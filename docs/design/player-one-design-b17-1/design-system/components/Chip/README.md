# Chip (17차 K2)

칩 3종을 나눠요.

- `kind="info"` 값 칩 — 누를 수 없음, 회색 면 + 기울임. `label` + `value`(Barlow 이탤릭).
- `kind="filter"` 누르는 칩 — 32px, `selected`면 라임 면. 목록 거르기·하위 탭.
- `kind="status"` 상태 배지 — 테두리만, `tone` = success · fail · warning · injury · brand · mine.

보상(XP·카드 선택권·TP)은 정보 칩이에요. 라임 테두리로 버튼처럼 보이게 하지 않아요.
