# PointBar

배분 포인트 띠. 커스텀 생성 화면 위에 붙어서(`sticky`) 스크롤해도 늘 보여요.

- `left` = 남은 포인트(크게), `total` = 이번에 쓸 수 있는 전체(기본 100 + 나이 + 약발 + 태그), 막대 = 쓴 비율.
- `items` = 내역 칩 `[{ label: '기본', value: 100, base: true }, { label: '나이', value: 21 }, { label: '약발', value: -12 }, { label: '태그', value: -35 }]`. 양수 초록 `+21`, 음수 빨강 `−12`, 0은 회색. "기본 100 0(나이)"처럼 숫자 두 개가 붙지 않게 칩 하나에 이름 + 부호 숫자 하나.
- 상태(자동): 남음 = 라임 숫자 + "남았어요" · `0` = 초록 테두리 + "✓ 다 썼어요" · 음수 = 빨간 면 + "✕ nP 넘쳤어요 · 시작할 수 없어요"(시작 버튼은 막힘). `message`로 문구를 바꿀 수 있어요.
- 높이 약 76px(내역 한 줄). 바로 아래 콘텐츠가 가리지 않도록 sticky 띠 아래 6px 바닥색 띠가 붙어요.
- 남은 포인트를 다 쓰지 않아도 시작할 수 있어요(남은 포인트는 첫 레벨업 포인트로 넘어가요 — 기획 확인 필요). 넘치면 막아요.
