# Pitch

> **2부** — 가로 `size="sm"`(0.72배): PC 결정 순간처럼 피치를 800px 넘게 크게 그릴 때(218). PC에서는 [확대][전체] 단추 없이 전체 피치.

> **B · 가로 피치 확대 + 이름표 규칙 (요청 7~9 통합 · 189)** — 경기장은 항상 가로(왼쪽 → 오른쪽 공격). 결정 순간·결정 결과·하이라이트는 화면 맨 위 폭 가득 390×270.
> - `crop: [from, to]` 공격 방향 x 범위 %로 확대(결정 순간 기본 [44, 100] ≈ 1.8배). `cropY` 폭 방향 범위 %, 없으면 `aspect`(가로:세로, 폰 1.444) 비율로 공·내 선수 중심.
> - 확대해도 원·번호·이름표는 덜 커져요(1/zoom^0.62).
> - `names`(`all`|`mine`|`off`) · `collide` · `size`를 가로에서도 써요. 이름표 우선순위: 내 선수(시안 판) > 공 가진 선수(흰 판) > 공과 가까운 순. 자리: 원 아래 → 위 → 짧은 이름(`short`) 아래 → 위 → 그래도 겹치면 이름표 숨김(원·번호는 남김).

경기장(코트). 22명의 위치, 공, 방향 화살표, 오프사이드 라인을 그린다. 우리 팀은 오른쪽으로 공격한다.

- 소비자가 넣는 것:
  - `players` `[{ x, y, team: 'home'|'away', num?, me?, label?, flag?, dim? }]`: x·y는 0~100 비율(x는 우리 골 0 → 상대 골 100, y는 위 0 → 아래 100). 퇴장 선수는 배열에서 빼면 마커가 사라진다.
  - `ball` `[x, y]`.
  - `arrows` `[{ from:[x,y], to:[x,y], kind: 'pass'|'through'|'cross'|'dribble'|'shot', tone?: 'safe'|'balanced'|'gamble', curve?:[dx,dy], ghost? }]`: 패스·침투·크로스는 점선, 드리블은 지그재그, 슛은 굵은 흰 선. 결정 순간에는 선택한 선택지 화살표만 진하게, 나머지는 `ghost`로 옅게.
  - `offsideX`(0~100): 노란 점선 오프사이드 라인. `marks` `[{ x, y, text, tone }]`: 코트 위 짧은 라벨("코너킥", "GOAL").
- 색: 우리 팀 `team-home`(라임 채움 + 검은 번호), 상대 `team-away`(어두운 채움 + 주황 테두리), 내 선수는 흰 테두리 + `mine` 고리 + 이름표. 코트 바탕 `pitch`는 두 테마 모두 어둡다.
- 너비 100%, 비율 105:68(390 화면에서 358×232).

## 요청 5 · 세로 피치

- `orient="vertical"`: 폰 세로용. 내 팀이 아래에서 위로 공격(x 0~100은 그대로 우리 골 → 상대 골). `crop={[from, to]}`로 공격 방향 일부만 그린다(결정 순간 [56,100] 상대 진영, 하이라이트 [34,100]).
- `marker`: `number`(번호 원, 기본) · `face`(얼굴 + 팀 색 테두리, `player.face` 이미지 없으면 기본 얼굴) · `pixel`(도트 8×10 캐릭터, `dot` 2 = 16px · 4 = 32px, 정수배만).
- `size`: md · lg(1.25배) · xl(1.5배). `names`: all · mine(내 선수만) · off.
- **이름표 겹침 규칙**(세로 기본, `collide={false}`로 끔):
  1. 내 선수 — 시안 이름표, 항상 풀네임.
  2. 공 가진 선수(`ball: true`) — 흰 이름표, 항상.
  3. 나머지는 공에 가까운 순서로 마커 아래 → 위 순서로 자리를 찾는다. 다른 이름표·다른 마커와 겹치면
  4. 짧은 이름(`short`, 없으면 '.' 뒤 3자)으로 다시 시도하고,
  5. 그래도 겹치면 이름표를 숨기고 번호 원만 남긴다.
- 이름표는 반투명 검은 바탕(#121317 78%) 위 흰 글자 — 글자 그림자 없음.

## 요청 6 · 캐릭터(도트) 마커 유니폼·번호 띠

- `players[i].kit = { kit, kit2, pattern: 'solid' | 'stripe' | 'hoop', skin, hair }` — 경기마다 홈·원정·GK 유니폼이 자동으로 들어와요(설정 → 꾸미기 → 경기 아이콘에서 바꾼 값 반영).
- `band`(기본 켬): 캐릭터 아래 **등번호 띠** — 홈 = 라임(`team-home`), 원정 = 주황(`team-away`), 글자 = 검정. 유니폼 색이 뭐든 팀은 띠 색으로 읽어요.
- `kitClash`: 두 팀 몸통 밝기 차이가 작은 경기(예: 뉴캐슬 홈 S01 흑백 줄 vs 사우샘프턴 원정 C05 검정)에서 **원정 몸통에 주황 테두리**를 더해요. 계산은 게임 쪽(밝기 차이 기준값은 코드에서 정함).
- 유니폼 코드(S01·C05)는 경기 화면에 쓰지 않아요(캡처의 디버그 문구 제거) — [보기] 시트·설정에서만.
