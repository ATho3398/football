# TacticEmblem

전술 성향 6종 엠블럼: 균형 `balanced`, 티키타카 `tikitaka`, 게겐프레싱 `gegen`, 역습 `counter`, 직선(롱볼) `direct`, 수비 블록 `block`.

- 모서리 하나를 사선으로 깎은 사각 바탕(`surface-3`) + 2px 선 아이콘. 내 팀은 `brand-ink`, 상대 팀(`away`)은 `away` 색.
- 선택된 칩 안(`on`)에서는 `on-brand` 바탕 + 라임 글리프.
- 칩, 스코어 바, 홈의 다음 경기 카드, 팀 정보에 공용으로 쓴다. 아이콘 이름은 `t-balanced` 등.
