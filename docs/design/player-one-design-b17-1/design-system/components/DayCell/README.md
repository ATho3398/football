# DayCell

주간 훈련 7칸의 한 칸. 폰 390에서 7칸(약 47px)이 들어가도록 줄을 줄였다.

- 요일(11px) · 날짜(Poppins 16px) · 아이콘(18px) · 훈련 이름(12px 800, 2글자: 기술·고강·포지·세트·영상·회복·휴식·경기).
- `today`: 라임 면 + 아래 "오늘" 꼬리표. `fixed`: 아이콘 옆 작은 자물쇠(경기 다음 날 휴식 고정). `kind="match"`: `surface-3` 면 + 공 아이콘. `selected`: 2px 라임 테두리. `past`: 흐리게.
- 전체 이름과 XP·체력 값은 하루 훈련 시트에서 보여 준다(칸 안에 숫자를 넣지 않는다).
