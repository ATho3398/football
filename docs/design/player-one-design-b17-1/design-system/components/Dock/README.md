> **B · 독 v3 (요청 7~9 통합 · 201) — 이 묶음에서는 아래가 우선이에요.**
> - 폰 5칸: **홈**(맨 왼쪽 일반 칸) · 선수 · **[다음]**(가운데 강조 키) · 훈련·일정 · 더보기. 열 너비 1fr · 1fr · 1.9fr · 1fr · 1fr. 따로 있던 초록 진행 알약과 가운데 홈 원은 없어요.
> - `progress`: `continue`(라임 · "계속" + 굵은 화살표) · `running`(어두운 면 + 라임 글자 · 아래 라임 줄 · "진행 중") · `match`(라임 · "경기") · `live`(라임 + 빨간 점 · "경기 중") · `locked`(회색 · 누를 수 없음). 키는 꺾인 사각형 높이 54px, 독 위로 12px 솟고 글자 Black Han Sans 18px(진행 중·경기 중 16px).
> - `moreOpen`: 독 위 한 줄(78px, 아래 12px은 솟은 키 자리) — 인박스 · 재정 · 월드 · 덱 · 전술 · 설정 · 저장, 칸 64px, 좌우 끌기(`moreScroll: 'start' | 'end'`). 화면 배경을 막지 않아요. 접힌 동안 인박스·재정 배지는 더보기 칸에 합산.
> - 켜진 칸: 라임 아이콘·글자 + 위 꺾인 라임 막대 26×4. 배지는 빨간 숫자.
> - PC: 홈 · 선수 · 덱 · 전술 · 인박스 | [다음] 176px | 훈련·일정 · 월드 · 재정 · 설정 · 저장(더보기 없음).
> - 경기 중 다른 화면 띠는 시안 대신 그래파이트 + 빨간 점 + 아래 라임 줄(시안은 내 선수 표식에만).

하단 고정 메뉴. 폰 6칸 · PC 9칸. **요청 6부터 홈이 항상 가운데**예요(5차까지는 진행 칸이 가운데).

- 폰: **진행**(2칸 폭 알약) · 선수 · **홈**(가운데 원) · 훈련·일정 · 월드 · 더보기. 열 너비 2fr · 1fr · 72px · 1fr · 1fr · 1fr — 왼쪽 3fr = 오른쪽 3fr이라 홈이 정확히 가운데예요. 덱·전술·설정·저장은 더보기 시트 안.
- PC(`device="pc"`, 1280 이상): 진행 · 선수 · 훈련·일정 · 덱 · **홈** · 전술 · 월드 · 설정 · 저장. 홈은 5번째(가운데) 132px 칸, 가운데 960px.
- **홈 키**: 56px 원(PC 44px), 독 위로 20px 솟아요. 평소 = `surface-3` 원 + 2px 라임 테두리 + 라임 아이콘, 홈 화면일 때(`value="home"`) = 라임 면 + 검정 아이콘. 독 바탕색 5px 고리로 독 윗선과 떼어 놓아요(그림자·발광 없음).
- **진행 칸**(`progress`): 아이콘 + 이름이 한 알약 안에. 상태 5종·색·배지 규칙은 그대로예요.
  - `continue` 계속(라임 · ›) · `match` 경기(라임) · `live` 경기 중(시안 + 빨간 점) · `answer` 답하기(주황 · 말풍선, 배지 = 남은 응답) · `season` 시즌 요약(라임 · 트로피).
- `value` = 지금 화면 칸(라임 글자). `badges` `{ player: 35 }` = 찍을 포인트 등. `locked` = 잠긴 칸(흐리게 + 작은 자물쇠, 누를 수 없음). 홈은 잠그지 않아요.
- 높이 폰 72px(홈 원이 20px 솟음) · PC 64px. 화면 콘텐츠는 독 높이만큼 아래 여백을 둬요.
- 경기 중에 다른 화면으로 가면 진행 칸은 `live`, 화면 맨 위에 시안 "경기 중 · 63' 1-0 [경기로 돌아가기]" 띠를 붙이고 하루 진행·자동 진행·덱·저장은 잠가요(전술은 하프타임·재개 대기 때만).
