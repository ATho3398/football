# PLAYER ONE — 디자인 핸드오프

싱글 플레이 축구 커리어 웹 게임 **PLAYER ONE**의 UI 디자인 묶음이에요. 이 문서를 먼저 읽고 구현을 시작하세요.

- 기준 화면: 모바일 세로 **390×844**, 한국어 UI, 다크 테마 우선(라이트 토큰도 있음).
- 스타일 이름: **볼트(Volt)** — 어두운 그래파이트 바탕 + 평평한 볼트 라임(#d6ff3c) 면. 발광·그라데이션 장식, 스크린톤(망점), 글자 그림자는 쓰지 않아요.
- 화면의 문구·수치는 기획서 규칙에 맞춰 두었어요. 기획서와 다르면 **기획서가 우선**이에요.

## 폴더 구조

```
player-one-design/
├─ HANDOFF.md                  ← 지금 이 문서
├─ index.json                  ← 화면 번호·그룹·이름·크기·파일 경로 목록
├─ design-system/
│  ├─ README.md                ← 브랜드 규칙(색·글꼴·카드·전술·화면 골격). 반드시 읽기
│  ├─ tokens.json / tokens.css ← 디자인 토큰(다크/라이트) · CSS 변수 + @font-face
│  ├─ fonts/                   ← Pretendard Variable, Poppins 500~800
│  └─ components/
│     ├─ bundle.js / bundle.css ← 컴포넌트 기준 구현(React 18, window.PlayerOne.*, po- 클래스)
│     ├─ index.d.ts            ← 모든 컴포넌트 props 타입
│     └─ <컴포넌트>/README.md   ← 컴포넌트별 규칙 (+ preview.html)
└─ screens/
   ├─ index.html               ← 전체 화면 갤러리(브라우저로 열기)
   ├─ png/                     ← 화면 캡처 56장 = 시각 기준
   ├─ html/                    ← 화면별 실행 가능한 HTML(실제 컴포넌트로 렌더)
   ├─ source/                  ← 캔버스 원본(.dc.html)
   └─ lib/                     ← html 화면용 React·번들·토큰·폰트·작은 런타임
```

## 화면 보는 법

- 가장 빠른 길: `screens/png/` 이미지.
- 실제 렌더: `screens/index.html`을 브라우저로 열기. 안 열리면 `screens/`에서 `python3 -m http.server`.
- 각 html은 `<template id="tpl">`(마크업)과 `<script id="code">`(그 화면의 샘플 데이터 `renderVals()`)로 되어 있어요. `<x-import component-from-global-scope="PlayerOne.X" kebab-props="{{값}}">` = 컴포넌트 X에 props 전달, `<sc-for>` = 반복, `<sc-if>` = 조건부. 화면마다 어떤 컴포넌트에 어떤 데이터가 들어가는지 여기서 읽을 수 있어요.

## 구현 가이드 (클로드 코드에게)

1. **토큰부터.** `tokens.json`/`tokens.css`를 프로젝트 테마로. 색은 토큰 변수로만. 테마는 `<html data-theme="dark|light">`.
2. **컴포넌트는 `bundle.js`가 기준 구현.** TSX로 옮길 때 `index.d.ts` props와 `bundle.css` 클래스·치수를 지키세요.
3. **화면은 `screens/png`에 맞추고**, 구조·데이터는 `screens/html`의 template·code를 따르세요. 샘플 데이터는 실제 게임 데이터로 교체.
4. 컴포넌트 README의 문구 형식·상태 표현 규칙을 지키세요. 아이콘은 `Icon` 내장 SVG만 사용.

## 꼭 지킬 규칙 요약

- 라임(`brand`)은 면으로, 한 화면에 한 번 크게(`HeroPanel`). 숫자는 문장으로 설명. 확률 변화는 ▲초록 / ▼빨강 + 출처("+8 카드").
- 숫자 글꼴 Poppins, 한국어 Pretendard, 해요체.
- **카드 종류 7종:** 플레이 · 세트피스 · 패시브 · 콤보 · 관리 · 시그니처 · 지시(5단계에서 활성).
  - **포지션군 태그**(공용/공격/미드/수비, `pos`)는 종류와 별개. 수비 플레이 카드 = `type: 'play'` + `pos: 'def'`.
  - **지시**는 `order: 'follow'`(이행 = 내가 정한 역할대로 팀플레이 → 팀 결과·감독 신뢰도 +) / `'solo'`(독단 = 역할을 벗어난 개인 플레이 → 성공 시 평점 +0.8, XP ×1.3 / 실패 시 감독 신뢰도 −5). 기준은 사용자가 전술 화면에서 정한 슬롯 역할.
  - **시그니처**는 모두 희귀, 그 역할일 때만 사용(아래 표). 역할이 다르면 회색 + "역할 불일치" + [교체 제안].
  - 라보나 크로스 = 에픽 · 플레이 · 공격(시그니처 아님).
- 덱: 세트피스 최대 3장, 같은 카드 최대 2장. 덱 슬롯은 **위상 티어에 따라 8~14장**(일반 티어 김민준은 8장부터, 면담 보상 +1을 받아도 최대 14). 덱 화면 샘플은 8장 기준.
- 포지션 라벨은 CAM/CDM(AM/DM 쓰지 않음).
- 위상 표기: 티어 이름(일반/스페셜/탑클래스/월드클래스/레전더리) + 점수. 예: "위상 일반 · 12점".
- 결정 순간 패널: 선택지 3개(안전/균형/도박) → 패 카드 줄 → [맡기기](보조) [확정](주). 플레이 카드를 고르면 카드 희귀도 색 테두리의 4번째 선택지.

- **경기 = 하이라이트(요청서 4).** 경기당 약 90초, 장면 6~8개(각 10~15초, 1× 실제 속도, 공격이 시작되는 순간부터). 장면 사이 약 1초 전환: 선수가 다음 위치로 미끄러지고, 시계가 넘어가고, 피드에 요약 한 줄.
  - 상단 띠(`ScoreBar` `view`): 하이라이트 "하이라이트 · 장면 3/7 · 23' 역습" + [여기서부터 실시간] / 장면 전환(배속·실시간 비활성) / 실시간 "실시간 · 31'" + [하이라이트로 돌아가기] / 하프타임은 "하프타임"만. 결정 순간도 장면의 하나라 띠 유지. 재개 대기는 띠 아래 "스로인 준비" 라벨(`sceneNote`). 샘플 장면 수는 7.
  - 띠 오른쪽 끝 **톱니 = 경기 설정 시트**(정지 빈도·빨리 감기).
  - 배속 1×/2×/4×는 장면 안에서만. 건너뛰기(⏭)는 **경기 전체**: 남은 경기를 바로 계산해 결과 화면으로. 다음 장면으로 넘기는 버튼은 없음. 확인 모달 "경기 결과로 건너뛸까요?", 직접 모드면 "남은 결정 순간은 엔진이 대신 골라요. 카드는 쓰지 않아요." 한 줄 추가.
- **버전 표시:** 홈 맨 아래·경기 설정 시트·타이틀에 보조 글씨 "버전 C.18 · 엔진 6 · 밸런스 14 · 2026-10-15 배포 (커밋 82e27e0)". 세이브 시작 버전이 다르면 홈에 중립 배너, 세이브 슬롯마다 "C.16에서 시작".
- **경기 후 평균 위치:** 리포트 탭 "전술 리포트 · 평균 위치"에 양 팀 11명 평균 위치(정지 피치, 홈 팀이 오른쪽으로 공격).

## 수치 규칙 (화면에 쓴 값)

- **감독 신뢰도:** 보상 면담은 신뢰도 80 이상. 경기 후 예시 +4(평점 7.0 이상 +2, 골 +1, 승 +1). 훈련은 신뢰도에 영향 없음.
- **보상 면담 선택지:** 선호 슬롯 보장(다음 5경기) · 덱 슬롯 +1(이번 시즌, 최대 14장) · 주전 보장.
- **경기 후 XP 예시:** +25(다음 레벨까지 200 기준).
- **주전 경쟁 점수** = 슬롯 OVR + 신뢰도 보정 + 폼 보정 + 피로 보정. NPC 경쟁자의 신뢰도 보정은 +0.6(신뢰도 60 고정), 피로 보정은 피로 70 이상일 때만 −2. 예: 김민준 62.4(60 + 0.6 + 1.8) vs 오현우 64.1 → 선발 확률 24%.
- **훈련(하루):** 기술 XP +1.0 · 피로 −3.5 / 고강도 +1.5 · −2 / 포지션·역할 +0.5 · −4 / 세트피스·카드 +0.5 · −4 / 영상 분석 +0.5 · −4.5 / 회복 0 · −5.5 / 휴식 0 · −6. 묶음 게이지는 하루 +1칸(30칸), 주간 XP 상한 6.
- **휴가:** 휴가 중에는 폼이 떨어지지 않음. 리그 외 경기가 있으면 그 일정에서 멈춤.
- **이적시장:** 여름 시장은 개막 전(비시즌)까지, 겨울 시장은 1월. 9월 샘플에는 이적시장 배지 없음.
- **날짜 샘플:** 9/2 A매치 휴가(9/8까지, 9/5 리그컵에서 멈춤) → 9/9 하루 진행 → 9/12(토) 리그 5R 리버풀전 → 9/14~20 훈련 주간, 9/19 리그 6R.
