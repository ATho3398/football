# Dock

하단 고정 메뉴. 폰 6칸 · PC 9칸.

- 폰: 홈 · **진행** · 선수 · 훈련·일정 · 월드 · 더보기. 덱·전술·설정·저장은 더보기 시트 안.
- PC(`device="pc"`, 1280 이상): 홈 · 진행 · 선수 · 훈련·일정 · 덱 · 전술 · 월드 · 설정 · 저장. 아이콘 + 이름 한 줄, 가운데 960px.
- 가운데 **진행** 칸(`progress`)은 상태에 따라 이름·아이콘·색이 바뀌고 늘 면으로 강조된다.
  - `continue` 계속(라임 · ›) · `match` 경기(라임 · 경기) · `live` 경기 중(시안 + 빨간 점) · `answer` 답하기(주황 · 말풍선, 배지 = 남은 응답) · `season` 시즌 요약(라임 · 트로피).
- `value` = 지금 화면 칸(라임 글자). `badges` `{ player: 35 }` = 찍을 포인트 등. `locked` = 잠긴 칸(흐리게 + 작은 자물쇠, 누를 수 없음).
- 높이 폰 72px · PC 64px. 화면 콘텐츠는 독 높이만큼 아래 여백을 둔다(독 뒤로 내용이 숨지 않게).
- 경기 중에 다른 화면으로 가면 진행 칸은 `live`, 화면 맨 위에 시안 "경기 중 · 63' 1-0 [경기로 돌아가기]" 띠를 붙이고 하루 진행·자동 진행·덱·저장은 잠근다(전술은 하프타임·재개 대기 때만).
