# OfferCard

이적 제안 카드. 엠블럼·구단·리그 순위, 팀 전력 · 예상 출전 · 예상 선발 · 계약 4칸, 주급·연봉, [거절][수락].

- `offer.loan`: "임대" 주황 꼬리표, 계약 칸 이름이 "임대 기간"으로 바뀐다.
- 목록에서는 하나만 펼치고(선택된 제안) 나머지는 한 줄(엠블럼 · 구단 · 리그 순위 · 전력 차 · 선발 % · 계약)로 접는다. 주급이 모두 같으면 목록 위 한 줄로 빼고 카드마다 반복하지 않는다.
- 전력 차는 ▲초록/▼빨강으로, 위상에 영향(약팀 이적)이 있으면 `note`에 문장으로.

## 요청 6

- `tier` = 제안 구단 재정 등급 칩(4단 막대 + 글자, 머리 오른쪽). "임대"는 주황 칩이라 등급 칩과 모양이 달라요.
- `fee` = 이적료(계약 칸 아래 작게, 예 "이적료 118억 원"). 계약 만료면 `'자유계약'`.
- `homeClub` = "친정 · 유스 구단" 시안 칩(머리 아래). 1군 테스트 합격 뒤·유스 출신 구단의 제안에 붙어요.
- 구단이 거절한 제안은 카드가 아니라 화면 위 회색 줄(취소선 + 자물쇠 + "바이아웃 이상이면 거절 못 해요")로 보여요(145).
