# DeckSlot

덱 편집의 슬롯 한 칸. 카드가 있으면 간략 카드(`GameCard` `mini`), 없으면 빈 슬롯(라임 테두리 + 버튼).

- 소비자가 넣는 것: `card`(없으면 빈 슬롯), `onClick`(카드: 빼기, 빈 슬롯: 카드 풀로 이동).
- 4열 그리드, 간격 `space-2`, 높이 `slot-h`(116px).
- 빈 슬롯 바탕: 45° 빗금. 흰색 5.5%와 1.5% 줄이 6px씩 번갈아 깔리고, 가운데 + 버튼은 그 위에 둔다.
- 덱 슬롯 수는 위상 티어에 따라 8~14장(일반 티어 8장부터, 면담 보상 +1을 받아도 최대 14). 덱 편집 화면은 채운 슬롯 + 빈 슬롯 뒤에 "다음 위상 티어 · 슬롯 +1" 잠긴 칸(자물쇠, 1px 선 테두리)을 하나 둔다.
