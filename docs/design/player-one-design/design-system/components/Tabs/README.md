# Tabs

탭 세 종류: 필터용 `segment`(따로 떨어진 알약, 선택은 라임 면), 화면 안 섹션용 `underline`, 하단 내비게이션 `nav`.

- 소비자가 넣는 것: `items` `[{ id, label, icon?, badge? }]`, `value`, `variant`, `onChange(id)`.
- 하단 탭은 홈, 경기, 선수, 커리어, 월드. 아직 없는 기능의 탭은 빼서 숨긴다.

- `fill`: 칸을 같은 너비로 꽉 채운다(세부 전술 3단계, 포메이션 5종 고르기).

## 요청 5 · scroll · cols

- `scroll`: 한 줄 가로 스크롤 + 오른쪽 28px 흐림. 설정의 섹션 이동 칩처럼 "다 보이지 않아도 되는" 줄에만.
- `cols`: n열 바둑판. **탭이 6개 이상이면 잘리지 않게 `segment` + `cols={3}`(폰 3×2)**. PC는 한 줄.
- 하단 내비게이션은 이제 `Dock`(아래)을 쓴다. `nav`는 예전 화면 호환용.
