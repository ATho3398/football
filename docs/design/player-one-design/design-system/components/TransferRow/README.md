# TransferRow

이적 소식 한 줄: 얼굴 · 이름 · 포지션 · 나이 · OVR · 계약 상태(계약 만료/출전 시간/이적료) · 원 소속 → 새 소속(엠블럼 14px).

- `mine`: 내 팀으로 오거나 떠나는 줄은 시안 테두리.
- `fill`: 바로 아래 "↳ 빈자리 보충 · 이름 포지션 나이 · OVR · ○○에서" 줄. 들여 쓰고 바탕 없이.

## 요청 6

- `fee` = 몸값(이적 때 값). 계약이 끝난 선수는 `'자유계약'`. 이동 줄 아래 "몸값 37억 원"으로 붙어요.
- `toTier` = 도착 팀 재정 등급(`빅클럽` · `상위` · `중위` · `하위`) — 도착 팀 이름 뒤 4단 막대 칩. 괄호 글자("(중위)")는 쓰지 않아요.
- 목록은 "리그 안" / "리그 밖" 두 묶음 머리줄로 나눠요(OVR이 갑자기 뛰어 보이지 않게).
