# Button

주 행동과 보조 행동 버튼. 52px 알약이 기본이고, 화면 하단에 보조/주 버튼을 반씩 나란히 둔다("시작 덱 복원 / 저장").

- 소비자가 넣는 것: `children`, `variant`(`primary` 라임 면 | `secondary` 어두운 면 + 라임 글자 | `ghost` | `danger`), `size`(`sm` 34px | `md` 44px | `lg` 52px), `icon`/`iconRight`, `block`, 나머지 `<button>` 속성.
- 한 화면(바텀시트 포함)에 `primary`는 하나만. 발광·그라데이션은 쓰지 않는다.
