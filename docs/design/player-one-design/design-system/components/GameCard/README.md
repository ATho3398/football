# GameCard

게임 카드. 그림은 위쪽에 단단한 경계로 잘리고(망점·글자 그림자 없음), 아래 단색 면에 이름·효과·조건을 둔다.

- 사선 분할: 그림은 오른쪽이 올라간 날카로운 사선에서 잘리고, 그 아래 희귀도 색 줄무늬 2줄을 넣는다.

- 크기:
  - `full` 280×392: 카드 상세, 획득 연출.
  - `deck` 168×235(full의 0.6배): 카드 풀, 경합 패널 카드 목록.
  - `mini` 4열 그리드 칸 너비 × 116: 덱 슬롯. 그림 + 아래 사선 이름 띠(희귀도 색 줄) + 이름.
  - `hand` 76×108: 경기 중 패. mini와 같은 간략형.
- 소비자가 넣는 것: `card` `{ name, type, rarity, level, effect: { pre, hi, post }, condition: { text, met, current }, art?, isNew?, count? }`, `size`, `state`(`normal`|`selected`|`disabled`|`locked`), `reason`, `onClick`.
- 효과는 숫자만 홀로 두지 않고 문장으로 쓴다: "프리킥에서 직접 슈팅을 고르면 성공 확률이 **+12%p** 올라가요." 강조 수치(`hi`)는 희귀도 색.
- 조건은 "조건 · 프리킥 능력치 60 이상"처럼 쓰고, `current`가 있으면 "✓ 충족 · 현재 64" 또는 "✕ 미달 · 현재 55" 칩을 붙인다.
- 희귀도 색(`--r`): 일반 `rarity-common`, 희귀 `rarity-rare`(라임), 에픽 `rarity-epic`, 전설 `rarity-legend`. 프레임 2px, 희귀도 칩, 효과 강조에 쓴다. 발광 없음.
- `art`가 없으면 기본 그림(조명 아래 골문·수비벽·공 궤적)을 그린다. 카드 그림은 나중에 이미지 URL로 바꾼다.
- 카드 몸통은 테마와 상관없이 `card-bg`(어두운 색)다.
- 종류(`type`) 7종: 플레이 `play`(새 선택지 아이콘 — 결정 순간에 선택지를 추가), 세트피스 `setpiece`, 패시브 `passive`, 콤보 `combo`, 관리 `manage`, 시그니처 `signature`(역할 전용, 역할이 안 맞으면 회색 + 교체 제안), 지시 `order`(5단계에서 활성).
- 지시 카드는 `order: 'follow' | 'solo'`로 나눈다. 칩은 "지시 · 이행"(고리 아이콘) / "지시 · 독단"(원 밖 화살표). 기준은 감독 지시가 아니라 사용자가 전술 화면에서 정한 슬롯 역할이다.
  - 이행 = 내가 정한 역할대로 팀플레이 → 팀 결과·감독 신뢰도 +.
  - 독단 = 역할을 벗어난 개인 플레이 → 성공 시 평점·XP 보너스, 실패 시 신뢰도 −.
- 포지션군 태그(`pos`): 공용 `all`, 공격 `att`, 미드 `mid`, 수비 `def`(방패 아이콘, 예전 '수비' 종류 아이콘). 정식 카드는 종류 칩 아래 줄에, 간략 카드는 희귀도 점 옆 작은 아이콘(공용은 생략). 예: 수비 플레이 카드 = `type: 'play'`, `pos: 'def'`.
- 예전 키 호환: `type: 'defense'` → 플레이 + 수비 태그, `type: 'solo'` → 지시(독단)로 그려진다.
