# GameCard

게임 카드. 그림은 위쪽에 단단한 경계로 잘리고(망점·글자 그림자 없음), 아래 단색 면에 이름·효과·조건을 둔다.

- 사선 분할: 그림은 오른쪽이 올라간 날카로운 사선에서 잘리고, 그 아래 희귀도 색 줄무늬 2줄을 넣는다.

- 크기:
  - `full` 280×392: 카드 상세, 획득 연출.
  - `deck` 168×235(full의 0.6배): 카드 풀, 경합 패널 카드 목록.
  - `mini` 4열 그리드 칸 너비 × 116: 덱 슬롯. 그림 + 아래 사선 이름 띠(희귀도 색 줄) + 이름.
  - `hand` 76×108: 경기 중 패. mini와 같은 간략형.
- 소비자가 넣는 것: `card` `{ name, type, rarity, level, effect: { pre, hi, post }, condition: { text, met, current }, art?, isNew?, count? }`, `size`, `state`(`normal`|`selected`|`disabled`|`locked`), `reason`, `onClick`.
- 효과는 숫자만 홀로 두지 않고 문장으로 쓴다: "프리킥에서 직접 슈팅을 고르면 성공 확률이 **+12%p** 올라가요." 강조 수치(`hi`)는 희귀도 색.
- 조건은 "조건 · 프리킥 능력치 60 이상"처럼 쓰고, `current`가 있으면 "✓ 충족 · 현재 64" 또는 "✕ 미달 · 현재 55" 칩을 붙인다.
- 희귀도 색(`--r`): 일반 `rarity-common`, 희귀 `rarity-rare`(라임), 에픽 `rarity-epic`, 전설 `rarity-legend`. 프레임 2px, 희귀도 칩, 효과 강조에 쓴다. 발광 없음.
- `art`가 없으면 기본 장면을 그린다 — 요청 6부터 단색 + 종류 아이콘(아래 "그림 없는 카드"). 예전 골문·수비벽·궤적 장면은 `placeholder: 'scene'`.
- 카드 몸통은 테마와 상관없이 `card-bg`(어두운 색)다.
- 종류(`type`) 7종: 플레이 `play`(새 선택지 아이콘 — 결정 순간에 선택지를 추가), 세트피스 `setpiece`, 패시브 `passive`, 콤보 `combo`, 관리 `manage`, 시그니처 `signature`(역할 전용, 역할이 안 맞으면 회색 + 교체 제안), 지시 `order`(5단계에서 활성).
- 지시 카드는 `order: 'follow' | 'solo'`로 나눈다. 칩은 "지시 · 이행"(고리 아이콘) / "지시 · 독단"(원 밖 화살표). 기준은 감독 지시가 아니라 사용자가 전술 화면에서 정한 슬롯 역할이다.
  - 이행 = 내가 정한 역할대로 팀플레이 → 팀 결과·감독 신뢰도 +.
  - 독단 = 역할을 벗어난 개인 플레이 → 성공 시 평점·XP 보너스, 실패 시 신뢰도 −.
- 포지션군 태그(`pos`): 공용 `all`, 공격 `att`, 미드 `mid`, 수비 `def`(방패 아이콘, 예전 '수비' 종류 아이콘). 정식 카드는 종류 칩 아래 줄에, 간략 카드는 희귀도 점 옆 작은 아이콘(공용은 생략). 예: 수비 플레이 카드 = `type: 'play'`, `pos: 'def'`.
- 예전 키 호환: `type: 'defense'` → 플레이 + 수비 태그, `type: 'solo'` → 지시(독단)로 그려진다.
- `card.art`(이미지 URL)를 넣으면 기본 그림 대신 그 이미지를 쓴다. 그림 칸은 **4:3(280×210)** 하나이고, 정식·덱·간략·패 카드가 모두 이 칸에서 잘라 쓴다. 생성은 3:2(1536×1024)로 하고 좌우 약 5.6%씩은 잘린다고 보면 된다. 4:3 칸 기준 좌표: 왼쪽 위 태그 x14–172·y14–36, 포지션 태그 x14–74·y42–64, 오른쪽 위 레벨 x200–266·y14–36, 사선 (0,206)→(280,172) 아래는 글자 패널. 덱 슬롯은 x35–245, 경기 중 패는 x66–214만 보인다. 인물·공·동작은 핵심 영역 x66–214·y70–166 안에 둔다.
- 그림 위치·확대 조정: `card.artPos` `{ x, y, zoom }`. `x`는 오른쪽으로 이동(%), `y`는 위로 올림(%)이고 둘 다 그림 칸(280×210) 크기 기준이다. 음수면 반대 방향. `zoom`은 확대 배율 1~4(기본 1 = 칸에 꽉 채움). 정식·덱·간략·패 카드에 똑같이 적용된다. 옮겨서 드러난 가장자리는 그림을 거울처럼 이어 붙여 채운다(아래쪽은 대부분 글자 패널에 가려진다). 많이 옮겨 이음새가 보이면 `zoom`을 조금 올린다. 예: 발이 사선에 걸리면 `{ y: 12 }`.
- `flip: true`면 그림을 좌우 반전하고, `rotate`(도, −45~45, 시계 방향 +)로 기울인다. 둘 다 그림 자기 가운데 기준이라 `x` 방향은 그대로다. 기울여 드러난 모서리도 거울 채움으로 메운다.
- 간략 카드(덱 슬롯 `mini`, 경기 중 패 `hand`)는 `card.artPosMini` 하나로 같이 맞춘다. 없으면 `artPos`를 그대로 쓴다. 정식·덱(`full`·`deck`)은 항상 `artPos`.
- `card.artSquare: true`면 그림을 1:1 원본 그대로 쓴다(4:3으로 미리 자르지 않는다). 가로(280)를 칸에 맞추고 세로는 칸(210) 밖으로 넘치므로, 칸에 안 보이는 위·아래는 `y`로 올리고 내려 고른다. 프레임·태그 자리는 그대로다.

## 요청 6 · 그림 없는 카드 (기본 장면 규칙)

- 우선순위: **내 그림**(설정 → 꾸미기 → 카드 이미지) › **기본 그림**(카드 일러스트 17장) › **기본 장면**.
- 기본 장면(`card.art` 없음)은 이제 **단색 바탕(#1a1d24) + 하프라인·센터서클(흰 7%) + 카드 종류 아이콘(희귀도 색 55%)**이에요(`placeholder: 'type'`, 기본값). 예전 "조명 아래 골문·수비벽·궤적" 장면은 `placeholder: 'scene'`으로 남겨 뒀어요.
- 이유: 덱에서 그림 카드와 섞이면 예전 장면은 "다른 화풍"처럼 보이고, 9장이 거의 똑같아 구분이 이름에만 기댔어요. 새 장면은 조용한 빈칸이라 "아직 그림 없음"으로 읽히고, 종류 아이콘이 달라 카드끼리도 구분돼요.
- 이름 띠·희귀도 줄·희귀도 점·포지션 칩은 그림 유무와 상관없이 같아요. 설정 목록 썸네일(4:3)도 같은 장면을 써요("그림 없음" 글자만 넣지 않아요).
- 못 쓰는 카드(mini·hand, `state="disabled"` + `reason`): 이유 칩은 카드 위쪽(이름표를 가리지 않음), 그림은 회색, 이름은 흐린 글자로 남아요.
