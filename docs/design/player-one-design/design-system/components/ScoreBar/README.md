# ScoreBar

경기 화면 상단 스코어/분 바와 속도 컨트롤.

- 소비자가 넣는 것: `home`, `away`, `homeScore`, `awayScore`, `minute`, `speed`, `paused`, `status`(결정 순간·골·오프사이드 등 정지 사유, 라임 칩), `homeRed`/`awayRed`(퇴장 수), `homePlayers`/`awayPlayers`(기본 11−퇴장), `onSpeed`, `onPause`, `onSkip`.
- 퇴장이 나오면 그 팀 이름 옆에 레드카드 아이콘 + "10명" 칩이 붙는다.
- 경기는 **하이라이트**로 본다: 경기당 장면 6~8개(각 10~15초, 1× 실제 속도), 장면 사이 약 1초 전환. 장면 안에서 내 선수가 공을 잡는 결정 순간에 멈춘다(`paused` + `status: '결정 순간'`).

- `homeTactic`/`awayTactic`(`{ tactic, formation }`)을 주면 아래에 양 팀 성향 칩(`TacticChip` `xs`)과 포메이션 줄이 붙는다.

- `mode`(`manual`|`auto`)를 주면 시간 칩 옆에 직접/자동 토글이 붙는다(경기 중 언제든 전환).
- `ff`: 재개 대기 구간 자동 빨리 감기 중 표시(시간 칩이 회색 + ▶▶ "빨리 감기").

## 상단 띠 (`view`)

- `view`를 주면 점수판 위에 띠가 붙고, 띠 오른쪽 끝에 **설정 톱니**(정지 빈도·빨리 감기 시트)가 늘 있다. `onSettings`, 시트가 열린 상태는 `settingsOn`.
  - `highlight`: "하이라이트 · 장면 3/7 · 23' 역습" + [여기서부터 실시간] + 장면 진행 눈금. `scene = { index, total, minute, label }`. 결정 순간도 장면의 하나라 띠를 유지("장면 5/7 · 85' 내 결정").
  - `transition`: 장면 사이 약 1초. "장면 전환 · 다음 4/7", 배속·실시간 버튼 비활성. 시간 칩은 `minuteTo`로 "23' → 31'".
  - `live`: [여기서부터 실시간]을 누른 뒤. "실시간 · 31'" + [하이라이트로 돌아가기]. 눈금 없음.
  - `halftime`: "하프타임"만.
- `sceneNote`: 장면 안의 상태 라벨(예: 재개 대기 "스로인 준비"). 띠 바로 아래 작은 칩. 아이콘은 `sceneNoteIcon`(기본 스로인).
- 배속 1×/2×/4×는 장면 안에서만 의미가 있다. `transition`·`halftime`에서는 배속 묶음이 흐려진다.
- 건너뛰기(⏭)는 **경기 전체** 건너뛰기다. 다음 장면으로 넘기는 버튼은 없다.
- 점수판이 없는 경기 화면(하프타임 등)에는 같은 띠를 `SceneStrip`으로 따로 쓴다.
