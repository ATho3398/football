# AttrTile · AttrGrid

능력치 박스(1~20). 선수 화면 바둑판, 포인트 찍기, 새 게임 미리 보기에 쓴다.

- `AttrTile`: 이름 · 숫자(Poppins 24px) · 다음 칸까지 막대 · 이번 시즌 변화 `delta`(+1 초록 / −1 빨강).
- 색 구간(숫자·막대·핵심 테두리 공통): **17+ `brand`(라임) · 15+ `success`(초록) · 13+ `tier-key`(하늘) · 10+ `ink`(흰) · ~9 `away`(주황)**.
- `keyAttr`: 포지션 핵심 능력치 = 구간 색 1.5px 테두리.
- 편집(`editable`): 아래 줄에 비용 "6P" + "OVR +0.5". `selected`면 바탕이 한 단 밝아지고 2px 라임 테두리 + [−][+] 버튼 줄(높이 32px). 고른 상태에서도 비용·OVR 변화는 계속 보인다. `add` = 이번 배분으로 오를 칸(+1 라임).
- `AttrGrid`: `groups` `[{ name, note?, items }]`를 묶음별로 그린다. 폰 4열(타일 약 84px, "공격 위치선정"까지 한 줄), PC 5열. 묶음: 몸 다루기 · 마무리 · 패스·시야 · 수비 · 스피드 · 피지컬 · 정신.
