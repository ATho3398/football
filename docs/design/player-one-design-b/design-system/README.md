> **B 테마 · 브로드캐스트** — 이 시스템은 PLAYER ONE 6차(볼트, A)를 그대로 복사해 모양만 바꾼 갈래예요. A는 따로 보존돼 있어서 언제든 돌아갈 수 있어요. 컴포넌트 이름·props는 A와 같고(HeroPanel만 `face`·`kit`·`name`·`unit` 추가), `components/bundle.css` 맨 끝 "B 테마" 블록과 `tokens.json`(글꼴·모서리)만 달라요.

## B 테마 규칙

- **배색은 A 그대로**: 그래파이트(`surface-*`) + 라임(`brand`). 라임은 사선 면·꺾인 버튼·등번호처럼 "면"으로.
- **꺾인 사각형**: 버튼·세그먼트 탭·뒤로 버튼·독 홈 키·진행 칸은 평행사변형(`clip-path`, 8px 꺾임). 모서리 토큰은 2~6px로 줄였고 둥근 알약은 쓰지 않아요. 칩은 `skewX(-8~-10deg)`.
- **숫자**: `font-display` = Barlow Condensed 이탤릭(600·700·800). OVR·점수·스탯 칸이 중계 그래픽처럼 보여요.
- **제목**: `font-head` = Black Han Sans — 머리말 제목, 큰 버튼(lg), 독 진행 칸, 미페 이름. 본문은 Pretendard 그대로.
- **머리말**: 어두운 바탕 + 오른쪽 라임 사선 면 2겹, 아래 2px 라임 줄. 큰 숫자는 왼쪽 라임, compact는 사선 면 위 검정.
- **미페 머리말**(`HeroPanel face`): 배경 투명 미페를 **색 처리 없이** 왼쪽 아래에 세우고, 뒤에 라임 등번호(`kit`, 두 자리면 작게), 아래 사선 검정 면이 몸 아래를 덮어요. 그 위에 이름(`name`, Black Han Sans) · 소속 줄(`eyebrow`) · 칩, 오른쪽 아래 OVR(`value` + `unit`). 홈 430px · compact(선수 화면) 290px.
- **섹션 제목**: 앞 막대는 22×5 꺾인 라임. 밑줄 탭은 꺾인 4px 라임.
- **독**: 위 2px 라임 줄, 홈 키 = 꺾인 사각형(홈 화면이면 라임 면). 진행 칸은 높이 44px, [계속]은 글자 17px + 굵은 화살표(글자 → 화살표 순서, 라임 단색 · 그라데이션 없음). PC는 40px · 14px.

PLAYER ONE은 선수 한 명을 17세부터 은퇴까지 키우는 싱글 플레이 축구 커리어 웹 게임이다. 스타일 이름은 **볼트(Volt)**: 어두운 그래파이트 바탕에 평평한 볼트 라임 면 하나로 힘을 주는 스포츠 앱이다. 모바일 세로(390×844)가 기본이고 다크 테마가 1순위다.

## 핵심 원칙

1. **라임은 면으로, 한 화면에 한 번 크게.** 화면 맨 위 `HeroPanel`(라임 헤더)이 그 화면의 대표 숫자 하나를 112px로 보여 준다. 나머지 라임은 주 버튼, 선택된 탭, 진행 바, 희귀 카드처럼 작게 쓴다.
2. **발광·그라데이션 장식 없음.** 그림자는 `shadow-card`, `shadow-sheet`만 쓴다. 빛나는 테두리, 금박, 흐르는 광택, 빛살은 쓰지 않는다(도박 사이트처럼 보인다).
3. **숫자는 문장 안에서 설명한다.** "+12"처럼 숫자만 홀로 두지 않는다. "성공 확률이 **+12%p** 올라가요."처럼 무엇이 얼마나 바뀌는지 같이 쓴다.
4. **확률과 보상은 숨기지 않는다.** 선택지에는 성공 확률과 성공/실패 평점 변화가 항상 붙는다.
5. **스크린톤(망점)과 글자 그림자는 쓰지 않는다.** 그림과 글은 단단한 경계로 나눈다. 글자는 그림 위가 아니라 단색 면 위에 둔다.

## 글쓰기

- 해요체로 짧게: "탭하면 빼기", "포인트 3개를 얻었어요". 감탄은 골과 레벨업에만.
- 경기 피드는 중계체 현재형: "우리 팀이 중원에서 점유를 가져옵니다".
- 카드 효과: "{상황}에서 {행동}하면 {무엇}이 **{수치}** 올라가요." 수치는 희귀도 색으로 강조한다.
- 카드 조건: "조건 · 프리킥 능력치 60 이상" + 현재 수치 칩("✓ 충족 · 현재 64" / "✕ 미달 · 현재 55"). "요건"이라는 말은 쓰지 않는다.
- 표기: 평점 소수 첫째 자리(`7.4`), 변화는 부호와 필요하면 둘째 자리(`−0.15`, 유니코드 마이너스). 확률 `42%`, 확률 변화 `+8%p`. 분 `85'`. 금액 억/만 원, 천 단위 구분. 덱 수 등 큰 숫자는 두 자리(`09`).
- 이모지는 쓰지 않는다.

## 색

- 바탕: `surface-0`(앱) → `surface-1`(카드 타일, 리스트 행, 패널) → `surface-2`(보조 버튼, 비선택 탭, 칩) → `surface-3`(트랙, 아이콘 원형 바탕). 구분선 `line`, 의미 있는 테두리 `line-strong`.
- 글자: `ink`, `ink-muted`(라벨), `ink-faint`(힌트). 모두 surface 위 4.5:1 이상.
- `brand`(볼트 라임 #d6ff3c)는 면으로만 쓰고 위 글자는 `on-brand`. 라임 면 위 트랙·옅은 칩은 `on-brand-soft`. surface 위 라임 글자는 `brand-ink`.
- `mine`(시안): 내 선수 표식. `away`(주황): 상대 팀.
- 상태색 `success`, `fail`, `warning`, `injury`, `neutral`은 글자·아이콘 색이다. 면이 필요하면 `*-soft`를 깔고, 항상 ✓/✕ 같은 기호나 단어를 같이 쓴다.
- 카드 희귀도: `rarity-common` 회색, `rarity-rare` 라임(=`brand`), `rarity-epic` 보라, `rarity-legend` 금색. 카드 2px 프레임, 희귀도 칩, 효과 수치 강조에만 쓴다.
- 위상 티어 5색 `tier-normal`~`tier-legend`, 평점 5단계 `rating-1`~`rating-5`, 폼 `form-1`~`form-5`, 피로 `fatigue-*`는 단색 채움으로만 쓴다.
- 게임 카드 몸통은 테마와 무관하게 `card-bg`(어두운 색)다.

## 글꼴

- `Pretendard Variable`(`--font-sans`): 모든 한국어. 스타일 `title-xl`, `title-lg`(카드·선수 이름 22px 800), `title`(섹션 17px), `body`, `body-strong`(카드 효과 문장), `label`, `caption`, `micro`.
- `Poppins`(`--font-display`): 숫자 전용. `num-hero`(112px, 히어로 숫자), `num-score`, `num-xl`(확률), `num-lg`, `num-md`, `num-sm`. 숫자에는 `.po-num`(tabular-nums)을 붙인다.

## 모양과 간격

- 모서리: 칩 6~8px, 탭 알약 `radius-sm`(10), 슬롯·선택지 `radius-md`(12), 카드·패널 `radius-lg`(20), 히어로 헤더 아래와 바텀시트 위 `radius-xl`(32), 버튼 `radius-pill`.
- 버튼 높이 `button-h`(52px). 화면 하단에 보조/주 버튼을 반씩 나란히 둔다.
- 간격: 화면 좌우 `space-4`(16), 슬롯 사이 `space-2`(8), 섹션 사이 `space-6`(24).
- 섹션 제목은 `SectionTitle`(라임 세로 막대 + 제목 + 오른쪽 안내).

## 게임 카드

- 정식 카드(`GameCard` `full` 280×392, `deck` 0.6배 168×235)는 위에서 아래로 이렇게 구성한다.
  - 그림이 카드 위쪽 절반을 덮고, 단단한 경계에서 끝난다(망점 없음). 경계는 오른쪽이 올라간 날카로운 사선이고, 바로 아래 희귀도 색 줄무늬 2줄(굵은 줄 + 반투명 가는 줄)을 넣는다(사선 분할).
  - 왼쪽 위에 희귀도 칩과 종류 칩, 오른쪽 위에 숙련도 칩.
  - 아래에 이름, 효과 문장 패널, 조건 줄.
- 덱 슬롯(`DeckSlot` → `mini`)과 경기 중 패(`hand`)는 간략 카드다. 그림 + 아래 사선 이름 띠(위 경계에 희귀도 색 줄) + 이름 + 희귀도 점만 넣는다.
- 카드 종류는 7종(플레이 · 세트피스 · 패시브 · 콤보 · 관리 · 시그니처 · 지시)이고, 포지션군 태그(공용 · 공격 · 미드 · 수비)는 종류와 따로 붙는다. 덱 편집 필터도 종류 줄과 태그 줄을 따로 둔다.
- 그림이 없으면 기본 그림(조명 아래 골문, 수비벽, 공의 궤적; 궤적은 희귀도 색)을 그린다. 실제 일러스트는 `card.art`에 이미지 URL로 넣는다.

## 전술

- 팀 전술은 사용자가 정한다(선발·교체는 감독 NPC). 세 층: 성향 6종 → 포메이션 5종 + 내 슬롯 + 슬롯별 역할 → 세부 전술 4개(3단계).
- 성향은 `TacticEmblem`/`TacticChip`으로만 표시한다: 균형, 티키타카, 게겐프레싱, 역습, 직선, 수비 블록. 상대 팀은 `away` 색.
- 적합도는 `FitBadge`(✓ 잘 맞음 / – 보통 / ✕ 안 맞음). 포메이션은 `FormationPitch`(세로, 내 슬롯 시안 링).
- 세부 전술은 라벨 + `Tabs` `segment` 3단계. 역할 고르기는 `BottomSheet` + `OptionRow`.
- 경기 중: `ScoreBar`의 `homeTactic`/`awayTactic`으로 스코어 아래에 양 팀 성향·포메이션을 작게 둔다. 스로인·골킥은 피드에서 흐리게(`faint`), 상대 전술 변경은 `tactic` 피드.

## 움직임

- 조용하게: 토스트·시트는 아래에서 올라오고, 결과 도장은 한 번 튀어나오며, 실패는 0.4초 흔들린다. 광택, 회전, 맥박 애니메이션은 없다.
- `prefers-reduced-motion`이면 모든 애니메이션을 끈다.

## 화면 골격

- 목록·편집 화면: `HeroPanel` → `SectionTitle` + 내용(좌우 16px) → 하단 버튼 두 개 또는 `Tabs` `nav`.
- 경기 화면: `ScoreBar`(맨 위 하이라이트 띠 + 설정 톱니) → `Pitch` → `FeedItem` 최근 몇 줄 → 내 선수 상태 줄 → `CardHand`. 경기는 **약 90초 하이라이트**로 본다: 장면 6~8개(각 10~15초, 공격이 시작되는 순간부터, 1× 실제 속도), 장면 사이 약 1초 전환(선수가 다음 위치로 미끄러지고, 시계가 넘어가고, 피드에 요약 한 줄). [여기서부터 실시간]을 누르면 그 뒤를 끊김 없이 본다. 장면 안에서 내 선수가 공을 잡는 결정 순간에 멈춘다.
- 결정 순간 패널: 위에서부터 선택지 3개(안전/균형/도박) → 패 카드 줄 → [맡기기](보조) [확정](주). 확률 카드를 고르면 확률이 바로 바뀌어 보이고(▲초록/▼빨강 + 출처), 플레이 카드를 고르면 카드 색 테두리의 4번째 선택지가 생긴다. 선택지를 누르면 `Pitch`에 화살표 미리보기. 침투 패스에는 오프사이드 위험을 붙인다. 진입은 0.5초 슬로모션 후 정지.
- 경기 진행: `ScoreBar`에 직접/자동 토글과 배속 1×/2×/4×(장면 안에서만), 건너뛰기(⏭ = 경기 전체를 계산하고 결과 화면으로). 재개 대기 구간은 빨리 감기(`ff`). 하프타임은 띠에 "하프타임"만, 재개 대기는 띠 아래 "스로인 준비" 같은 라벨(`sceneNote`).
- 퇴장: 그 팀 마커를 `Pitch`에서 빼고, `ScoreBar`에 레드카드 + "10명"을 붙인다.

## 요청 5 · 폰에서 한 화면에 담기

- **독**: 모든 화면 하단에 `Dock`(폰 72px · PC 64px). 콘텐츠는 그 높이만큼 아래 여백. 가운데 진행 칸이 "지금 할 일"(계속 · 경기 · 경기 중 · 답하기 · 시즌 요약). B: 진행 칸은 라임 꺾인 박스 높이 44px · 글자 17px, [계속]은 글자 다음에 굵은 화살표(그라데이션 쓰지 않음).
- **머리말**: 첫 진입 대표 숫자만 큰 `HeroPanel`. 탭으로 오가는 화면(덱·설정·월드·선수·시즌 상세)은 `compact`. 글자 머리말은 48px 한 줄 6자 이내.
- **긴 화면 줄이기**: ① 탭으로 나누기(선수 = 능력치·포지션·기록·계약·이적), ② 접기(설정 섹션은 한 줄 요약 + 펼치기, 첫 섹션만 펼침), ③ 요약 + 더 보기(경기별 4경기, 리그 스타 10명), ④ 안쪽 목록은 화면 안 스크롤 대신 별도 화면(선수 이름·페이스온). 기준: 폰 한 화면 = 844 − 독 72.
- **탭 6개 이상**: `Tabs` `segment` + `cols={3}`(3×2). 가로 스크롤 탭은 섹션 이동처럼 다 안 보여도 되는 곳에만(`scroll`).
- **세로 경기 화면**: `Pitch orient="vertical"`, 내 팀 아래→위. 이름표 겹침 규칙은 `Pitch` README.
- **결정 순간 한 화면**: 압축 스코어 줄 → 잘라 낸 세로 피치(상대 진영) → 선택지 2~4개(`ChoiceButton compact`) → 카드 패 칩 한 줄 → [맡기기][확정]. 모두 독 위에 들어간다.
- **빽빽한 곳**: 주간 7칸은 `DayCell`(요일·날짜·아이콘·2글자), 값은 시트에서. 능력치는 `AttrTile` 4열, 이름 줄임 없이.
- 단어 중간 줄바꿈 방지: 본문은 `word-break: keep-all`.

## 요청 6 · 커스텀·태그·카드 그림·홈 가운데

- **독**: 홈이 항상 가운데(폰 = 진행 2fr · 선수 · 홈 · 훈련·일정 · 월드 · 더보기 / PC = 5번째). 홈 키는 56px 원(라임 테두리, 홈 화면이면 라임 면). 진행 칸 상태 5종·배지·잠김은 그대로.
- **긴 입력 화면은 단계로**: 커스텀 생성 = 6단계(기본 · 몸 · 외모 · 태그 · 능력치 · 시작). 위 점 6개 + `PointBar`(sticky) + 아래 [이전][다음]. PC는 단계 목록이 왼쪽에 늘 보여요.
- **긴 목록은 묶음 탭 + 검색 + 거르기 + 정렬 + "n명 더 보기"**: 실제 선수 / 레전드 107명. 고른 항목은 목록 위에 고정 카드.
- **긴 이름 + 칩**: 이름 줄에는 이름만(한 줄, 말줄임). 칩(레전드·태그·등급)은 고정 자리(메타 줄 맨 앞, 카드 위 줄, 오른쪽 열)에 nowrap. 선수 이름은 통용 표기(요한 크루이프 · 호나우두 · 사비 에르난데스 · 데니스 베르캄프).
- **태그**: `TagChip` — 색 = 장점/단점/효과 없음, 앞 기호 = 종류(± 생성 · 핀 커리어 · 별 플레이 · 말풍선 스토리), 점선 + 시계 = 해제형, 취소선 = 해제됨. 태그 줄은 대표 4개(커리어·플레이 → 장점 → 단점, 최근 순) + [전체 보기] 시트.
- **재정 등급**: 4단 막대 + 글자(빅클럽 · 상위 · 중위 · 하위). 색을 쓰지 않아요. 표에서는 막대만.
- **설정 꾸미기**: 목록이 있는 4개(선수 이름 · 경기 아이콘 · 페이스온 · 카드 이미지)는 설정 안 한 섹션 "꾸미기"의 줄 4개 → 각각 하위 화면(위 이동 칩으로 서로 오감). 설정 본문에는 목록을 두지 않아요.
- **도트**: `PixelTile` 16px × 정수배, `image-rendering: pixelated`. 경기 화면 캐릭터는 번호 띠(홈 라임 · 원정 주황) + 비슷한 유니폼이면 원정 몸통 주황 테두리.
- **카드 그림 없음**: 단색 + 종류 아이콘 기본 장면(GameCard README).
- **경기 흐름**: 경기 준비(156) → 경기 → 끝나면 결과 화면 바로(155, [하이라이트 다시보기] 버튼). 다른 팀·선수를 누르면 상세(157 · 158, 읽기 전용). 훈련은 프리셋(159).

## 아이콘과 이미지

- 아이콘은 번들 내장 `Icon`(24px, 2px 선, `currentColor`)만 쓴다.
- 선수 얼굴(`Avatar`), 팀 엠블럼(`Crest`), 카드 그림은 지금 기본 이미지다. 교체 원본은 에셋 그룹 `Avatars`, `Crests`, `CardArt`에 있다.
- 로고는 아직 없다. 게임 이름은 Poppins 700 "PLAYER ONE".
