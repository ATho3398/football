# Stepper

− 값 + 조절. 나이·키·몸무게처럼 범위가 정해진 숫자 하나를 바꿔요(요청 6 커스텀 생성).

- `label`(위 왼쪽), `range`(위 오른쪽, 없으면 `min~max + unit` 자동), `value` + `unit`(가운데 Poppins 24px).
- `sub` = 가운데 아래 보조 줄. 값이 포인트·상한에 주는 영향을 짧게: "배분 포인트 +21" · "속도 상한 15 · 공중 상한 14". `subTone` = `gain`(초록, 포인트를 얻음) · `cost`(빨강, 포인트를 씀) · `warn`(주황, 상한이 내려감) · 없음(회색).
- `min`/`max`에 닿으면 그쪽 버튼이 흐려지고 눌리지 않아요. `disabled` = 전체 흐림(예: 실제 선수 모드).
- `size="sm"` = 52px 높이(두 개를 나란히 둘 때).
- 버튼 44×44, 보조 줄은 `word-break: keep-all`로 단어 중간에서 끊기지 않아요("공/중" 줄바꿈 해결).
