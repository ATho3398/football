# FormationPitch

세로 미니 피치(우리 골문이 아래). 11개 슬롯에 포지션 원 + 선수 이름 + 역할 칩.

- 좌표: `x` 0~100(왼→오), `y` 0~100(우리 골문 → 상대 골문).
- 내 슬롯(`me`): 시안 원 + 시안 링 + '나' 태그, 역할 글자도 시안. `ovr`이면 원 왼쪽 위에 내 OVR, `ovrDown`이면 손해 색.
- `selected`: 흰 링(역할 편집 중), `warn`: 실패색 링(주 포지션 밖), `dim`: 흐리게.
- 피치는 테마와 무관하게 어둡다(`pitch`). `compact`는 이름·역할을 숨긴 300px 높이.

- 커스텀 편집: `grid`로 보이지 않던 5레인 × 6줄 격자를 드러내고, `cells`로 놓일 칸(`target`, 라임)과 놓을 수 없는 칸(`bad`, 빨강)을 칠한다. 칸 `label`에 포지션 라벨(CAM, LW…). 끄는 선수는 `drag`, 원래 자리는 `ghost`.
