# TagChip

선수 태그 칩. **칩만 보고 종류·장단점·해제형을 알 수 있게** 세 가지를 따로 써요.

| 무엇 | 어떻게 보여요 |
|---|---|
| 장점 / 단점 / 효과 없음 | **색**: 초록(`success` + `success-soft`) / 빨강(`fail` + `fail-soft`) / 회색 테두리만 |
| 종류 | **맨 앞 기호** + 모양: 생성 태그 `+`/`−` 기호 · 모서리 6px 네모 / 커리어 태그 📍 핀 · 알약 / 플레이 태그 ★ 별 · 알약 / 스토리 태그 말풍선 · 알약 + "효과 없음" |
| 영구 / 해제형 | 영구 = 실선 면 / 해제형 = **점선 테두리 + 시계 아이콘**(조건을 채우면 사라져요). 해제 조건은 `release`(툴팁·시트에 표시) |
| 해제됨 | 면 없이 회색 + 이름 취소선(`released`) |

- props: `name`, `kind` = `gen`(생성) · `career`(커리어, 그 구단에서만 효과) · `play`(플레이, 경기 기록으로 얻음: 노익장·늦게 핀 꽃·빅매치 체질) · `story`(스토리, 효과 없음), `polarity` = `pro` · `con`(스토리는 무시), `release`(해제 조건 글), `released`, `scope`(커리어 태그 구단 — `showScope`면 칩 안에 작게), `desc`, `size` = `md`(28px) · `sm`(22px).
- 이름은 한 줄(`nowrap`), 넘치면 말줄임. 줄 안에서 칩 배경이 두 줄로 갈라지지 않아요.
- 긴 설명(효과·조건)은 칩 안에 넣지 않아요 — 태그 줄은 칩만, 설명은 [전체 보기] 시트의 줄(칩 + 설명 2줄)에서.
- 아이콘은 내장 `Icon`(pin · star · chat · clock)만 써요.
