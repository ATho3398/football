# HeroPanel

화면 맨 위의 라임 히어로 헤더. 그 화면의 대표 숫자 하나를 아주 크게 보여 준다(덱 수, 남은 포인트, 시즌 순위 등).

- 소비자가 넣는 것: `title`(가운데 제목), `right`(오른쪽 짧은 정보, 예: "12주차"), `onBack`(false면 뒤로 버튼 없음), `eyebrow`("경기 덱"), `value`·`total`(숫자는 두 자리로 맞춤, `pad:false`로 끔), `progress`(false면 진행 바 숨김), `chips`(문자열 또는 `{label, soft}`), children.
- 바탕 `brand`, 글자·진행 바 `on-brand`. 큰 숫자는 `num-hero`(Poppins 112px)이다. 그림자 숫자는 깔지 않는다.
- 아래 모서리 `radius-xl`(32px). 화면당 하나.

## 요청 5 · compact · 글자 머리말

- `compact`: 탭마다 반복되는 머리말(덱 "08/14", 설정, 월드 "17위", 선수 OVR)은 한 줄로 줄인다. 제목 줄 + [eyebrow 왼쪽 · 값 34px 오른쪽] + 칩 한 줄. 높이 약 130px(기본 260px). 한 화면의 맨 처음 진입(홈·시즌 요약 등 그 순간의 대표 숫자)에만 큰 머리말을 쓴다.
- **글자 머리말 규칙**: `value`가 숫자나 숫자+단위(위·세·점·명·P·일·R·골·개)가 아니면 글자로 본다. 글자는 Pretendard 800 48px 한 줄(compact는 22px), 6자 이내("계약 만료", "비시즌"). 길면 말줄임 — 대신 핵심어만 남기고 나머지는 eyebrow·칩으로 옮긴다(예: value "계약 만료", eyebrow "토트넘 홋스퍼 · 2018-19 시즌까지").
- 숫자 머리말은 그대로 Poppins 112px. 단위는 같은 크기로 붙여도 되지만 3자를 넘기지 않는다("5개" → value 5 + eyebrow "받은 제안").

## B 테마 · 미페 머리말 (`face`)

- `face` = 배경이 투명한 선수 미페 이미지(PNG/WebP). **색 처리 없이** 원본 그대로 왼쪽 아래에 세워요.
- `kit` = 등번호. 미페 뒤 오른쪽에 라임으로 아주 크게(Barlow Condensed 이탤릭 800). 두 자리면 작게(`is-two`).
- `name` = 큰 이름(Black Han Sans), `eyebrow` = 그 위 소속 줄(라임), `chips` = 이름 아래 꺾인 칩, `value` = 오른쪽 아래 OVR(흰색), `unit` = 그 아래 작은 글자("OVR · LW").
- 미페 바닥은 사선 검정 면(`surface-0`)과 라임 사선 띠가 덮어서, 상반신 컷이면 어떤 사진이든 잘린 자리가 보이지 않아요.
- 높이: 기본 430px(홈) · `compact` 290px(선수 화면). 제목 줄(뒤로 · 제목 · 오른쪽)은 위에 겹쳐요.
- 미페가 없으면 `face`를 빼요 → 일반 B 머리말(어두운 바탕 + 오른쪽 라임 사선 면).
