# Banner

> **B · 안내띠(203)** — 시안 테두리 대신 왼쪽 4px 막대(안내 = 라임, 성공 = 라임 면, 경고 = 주황, 부상 = 빨강) + 꺾인 액션 단추. 본문은 단어 단위 줄바꿈(keep-all). info 아이콘은 라임 글자(시안은 내 선수 표식에만).

화면 위쪽에 고정되는 상태 안내. 부상, 경고, 정보, 성공.

- 소비자가 넣는 것: `tone`(`injury`|`warning`|`info`|`success`), `title`, children(설명 한두 줄), `action`(버튼 라벨), `onAction`.
- 부상 배너는 복귀 예정 주를 반드시 적는다. 한 화면에 배너는 하나만.
