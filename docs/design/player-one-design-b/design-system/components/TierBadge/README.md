# TierBadge

위상 티어 배지. 5단계 눈금과 이름, 선택적으로 위상 점수를 보여 준다.

- 소비자가 넣는 것: `tier`(`normal` 일반 | `key` 스페셜 | `top` 탑클래스 | `world` 월드클래스 | `legend` 레전더리), `score`(0~1000, 선택), `size`(`sm`).
- 색: `tier-*` 단색 채움 + `on-fill` 글자. 발광·그라데이션 없이 색과 눈금 수로만 구분한다.
- 임시 점수 구간(코드에서 조정): 0~199 일반, 200~399 중요, 400~599 탑클래스, 600~799 월드클래스, 800~1000 레전더리.
- 표기는 '위상 {티어} · {점수}점'(예: 17세 김민준 = 위상 일반 · 12점). 키 `key`의 표시 이름은 '스페셜'.
