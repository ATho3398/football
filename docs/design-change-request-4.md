# 디자인 수정 요청 4 (Claude Design 입력용, 2026-10-15)

디자인 묶음(`docs/design/player-one-design/`, 47장)을 받은 뒤 바뀐 기획을 반영해 주세요. 기존 스타일(볼트), 토큰, 컴포넌트는 그대로 쓰고 **화면 상태만 추가·수정**합니다. 기획서 기준은 `docs/game-design.md` 부록 I.4, I.6, I.19, 21.5, 21.5.1, 24.3입니다. 코드 쪽은 이 수정본을 기다리지 않고 먼저 적용하니(부록 I.19), 다 되면 같은 폴더 구조로 덮어 주세요.

## 1. 경기 화면: 실제 속도 하이라이트 (15번 교체, 2장 추가)
경기를 4배속으로 처음부터 끝까지 보여 주는 방식은 폐기됐어요. 지금 방식:
- 경기당 **약 90초 하이라이트**: 장면 6~8개, 각 10~15초, 모두 **1× 실제 속도**. 장면은 공격이 시작되는 순간부터(빌드업·압박·침투가 보이게).
- 장면 사이 **약 1초 전환**: 선수들이 다음 장면 위치로 미끄러지고, 시계가 다음 장면 시각으로 넘어가고, 피드에 요약 한 줄이 떠요.
- **[여기서부터 실시간]** 버튼: 누르면 그 뒤를 끊김 없이 실제 속도로 봐요.
- 배속 1×/2×/4×는 장면 안에서만 의미가 있어요(전환 중 비활성).

## 2. 경기 후: 평균 위치 지도 (38번 수정)
- 전술 리포트 옆(또는 탭)에 **평균 위치 지도** 한 장: 우리·상대 11명의 평균 위치를 정지 피치에 마커로. 홈 팀이 오른쪽으로 공격하는 방향.

## 3. 버전 표시 (22번, 21번, 43번 수정)
- 홈 맨 아래와 설정 시트에 작은 보조 글씨: "버전 C.18 · 엔진 6 · 밸런스 14 · 2026-10-15 배포 (커밋 82e27e0)".
- 세이브 시작 버전이 지금과 다르면 홈에 중립 배너 한 줄: "이 세이브는 C.16에서 시작했어요. 이전 버전으로 진행된 경기 기록이 섞여 있어요".
- 세이브 슬롯(43)마다 보조 줄 "C.16에서 시작".

## 4. 숫자 바로잡기
- 덱 슬롯은 **위상 티어에 따라 8~14장**이에요(일반 티어 김민준은 8장부터). 면담 보상 +1을 받아도 최대 14장. 덱 화면(32~35) 샘플을 "8/8" 기준으로 바꿔 주세요.

## 5. 정해진 것 (HANDOFF "아직 정하지 않은 것")
- 경기 중 설정 시트(정지 빈도·빨리 감기)를 여는 버튼: **경기 화면 상단 바 오른쪽 톱니 아이콘**.

## 6. 디자인이 없는 기존 화면 (있으면 좋음, 우선순위 순)
지금 게임에 있지만 디자인이 없는 화면이에요. 코드는 컴포넌트로 먼저 조합해 두고, 디자인이 오면 맞춥니다.
1. 포인트 찍기(I.7): 남은 포인트, OVR 현재 → 예상, 능력치 25개(묶음 접힘, 비용, +1당 OVR 변화), 비용 구간 코치 코멘트.
2. 시즌 종료 요약(I.13): 순위, 업적 XP, 능력치 변화(자동 성장/노련함/노화), 위상 진행도.
3. 새 게임(I.2): 시작 방식(가상 유망주/실제 선수), 포지션 12개, 이름, 난이도, 실제 선수 목록.
4. 순위표와 리그 스타 선수(I.10 일부).
5. 타이틀, 은퇴 요약(I.14).
