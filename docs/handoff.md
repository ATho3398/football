# 인수인계 (코드 세션 → 기획 세션)

기획 세션은 코드를 건드리지 않고 `docs/game-design.md`를 작성한다. 확정된 내용은 바로 문서에 반영한다. 코드 세션은 그 문서를 읽고 구현한다.

먼저 `docs/design-notes.md`와 `docs/players-2018-draft.md`를 읽을 것. 아래는 그 이후 대화에서 새로 정해진 내용이다.

## 확정된 것

### 시작 방식
- 새 게임에서 둘 중 하나를 고른다
  1. 가상의 유망주를 직접 만든다
  2. 2018년 실제 선수 중에서 고른다
- 포지션은 골키퍼만 제외하고 자유롭게 선택
- 포지션별 OVR 계산이 필요하고, 커리어 중 포지션 전환(적응 페널티 등)을 열어둘지는 기획에서 결정

### 능력치와 랜덤 생성
- 필드 플레이어 능력치 25개, 7개 묶음 (자세한 목록은 `design-notes.md`)
- 골키퍼는 NPC 전용(플레이 불가). 유형 2개(스위퍼/클래식), 능력치 4개
- 데이터에는 능력치 중심값만 기록하고, 새 게임 시작 시 시드로 랜덤 생성
- 3단계 운(선수 전체, 묶음별, 개별)으로 합산해서 비슷한 능력치끼리 같이 움직이게 함
- 구현 완료: `src/attributes.ts`, `src/types.ts`, `src/rng.ts`, `src/generate.ts`, 샘플 `data/players/messi.ts`, 테스트 5개

### 선수 데이터 입력 방식 (비용 절감)
선수 700명 이상에 능력치 25개씩 전부 손으로 쓰면 비용이 너무 크므로 등급제로 입력한다.

| 등급 | 대상 | 입력 방식 | 대략 인원 |
|---|---|---|---|
| A | 월드클래스급 스타 | 능력치 25개 직접 입력 | 80~100명 |
| B | 주전급 | 포지션 + 아키타입 + OVR + 장점/단점 몇 개로 자동 생성 | 300~400명 |
| C | 나머지, 가상 선수 | 포지션 + OVR 범위만으로 완전 자동 생성 | 나머지 |

- 아직 합의 전: 등급제 최종 동의, A등급 인원 수(80명 제안)

### 기술 방침
- 웹(TypeScript)으로 만들고, AI API 없이 순수 코드로 동작 (런타임 AI 호출 0, 서버 0, 오프라인 가능)
- 저장은 브라우저 저장소
- 경기 중계와 스토리 기사 텍스트는 문장 템플릿을 미리 작성해 조합하는 방식
- 직접 축구 플레이는 없음. 경기는 시뮬레이션

## 개발 단계안 (수직 슬라이스 우선)

| 단계 | 내용 |
|---|---|
| 0 | 방향 확정, 스키마, 생성기 (거의 완료) |
| 1 | 최소 플레이 루프: 내 선수 생성 → 주 단위 진행 → 훈련 → 경기 시뮬(확률 기반, 텍스트 결과) → 시즌 종료/노화. 선수는 A등급 30~50명 + 자동 생성 |
| 2 | OVR/티어/위상 계산, 레전드 배지, 부상/폼 |
| 3 | 계약/이적 시장, 스토리 텍스트 |
| 4 | 선수풀 확장 (B/C 등급 대량 입력, 2부 리그, K리그) |
| 5 | 2D 피치 연출, 웹 UI 다듬기, Tauri/Capacitor 포장 |

경기 시뮬은 처음엔 결과와 내 선수의 평점/골/어시스트만 계산하고, 장면 단위 중계는 나중으로 미룬다. 2D 연출은 마지막에 하되 데이터 구조만 미리 호환되게 잡는다.

## 기획 세션에서 정해야 할 것

1. 플레이 길이: 몇 시즌, 은퇴까지인지 (기본안: 17세 시작, 은퇴까지 약 15~20시즌)
2. 시간 진행 단위 (기본안: 주 단위)
3. 경기 보기: 매 경기 텍스트 중계 vs 결과 중심 + 중요 경기만 중계 (기본안: 후자)
4. 포지션 전환 규칙, 포지션별 중요 능력치
5. 훈련 시스템 (무엇을 선택하고 어떻게 성장하는지)
6. 성장/노화 곡선, 잠재력 공개 방식(숨김값이 어떻게 드러나는지)
7. 부상, 폼, 컨디션 규칙
8. 위상(명성)과 레전드 배지 획득 조건 상세
9. 계약, 이적, 에이전트, 연봉, 스폰서의 난이도와 현실성
10. 대표팀(월드컵 등), 국제 대회 포함 여부
11. 스토리/이벤트 방향 (예: 라이벌, 언론, 가족)
12. UI 참고 게임과 첫 화면 스타일 (FC 커리어, FM, 텍스트 스토리 게임 등)
13. K리그, 챔피언십, 독일 2부, 에레디비지 선수는 직접 제공할지, 가상 선수로 대체할지
14. 난이도 설정 유무
15. 작업에 쓸 수 있는 대략적인 예산이나 세션 횟수 (단계 범위 조절용)
