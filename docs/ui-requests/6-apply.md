## 0. 공통 규칙 (모든 패치)

1. 5차 명세(`5-apply.md`) 0절 규칙 그대로(토큰·compact 머리말·독 여백·`keep-all`·샘플 수치는 디자인용).
2. **5차보다 6차가 우선**: 독(154), 경기 끝 = 결과 화면(155), 통용 이름, 경기 준비(156), 훈련 프리셋(159), 다른 팀·선수 상세(157·158). `5-apply.md` 0a절과 같은 내용이고, 이제 디자인이 있다.
3. **설정 "꾸미기"**: 설정(66)에는 목록을 두지 않는다. "꾸미기" 섹션에 한 줄씩(선수 이름 71 · 경기 아이콘 137/138 · 페이스온 68 · 카드 이미지 140~142) → 각 하위 화면(뒤로 가기), 하위 화면 위 꾸미기 이동 칩 4개.
4. **선수 화면 탭 5개**: 능력치 · **몸·태그** · 포지션 · 기록 · 계약(5차 4탭에 "몸·태그" 추가). 몸값·바이아웃·재정 등급은 계약 탭.
5. **태그 칩 = `TagChip`** 하나로 통일: 색(장점 초록 / 단점 빨강 / 효과 없음 회색 테두리), 맨 앞 기호(± 생성 · 핀 커리어 · 별 플레이 · 말풍선 스토리), 해제형 = 점선 + 시계, 해제됨 = 취소선. 칩 안에 설명 넣지 않기(설명은 시트 줄).
6. **긴 이름**: 이름 줄은 이름만 한 줄 말줄임, 칩은 고정 자리 `nowrap`. 클럽 이름은 한글로 통일(실제 선수 목록 영문 표기 정리).
7. **그림 없는 카드** 기본 장면 = 단색 + 하프라인 + 종류 아이콘(희귀도 색 55%) — `GameCard` 기본값 변경(옛 골문 장면은 `placeholder: 'scene'`). 못 쓰는 카드 이유 칩은 위로(이름 가리지 않게).

## 4. 확인 필요 (사용자 결정, 추천안 포함)

1. **모바일 독 칸 수**: 디자인 154 = 6칸(진행 · 선수 · 홈 · 훈련·일정 · 월드 · 더보기). C.50 코드 = 5칸(월드를 더보기 맨 위로). → **추천: 디자인 6칸**(390 폭에 들어가고 월드를 한 번 덜 누름). 5칸으로 갈 거면 154의 월드 자리를 비우고 열 너비만 `2fr 1fr 72px 1fr 1fr`.
