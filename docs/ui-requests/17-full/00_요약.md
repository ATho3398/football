## 1. 한 쪽 요약

**게임 한 줄**: 축구 선수 **한 명**의 커리어 — 17세 유망주(또는 실제 2018-19 선수·레전드·커스텀 선수)로 데뷔해 은퇴까지. 감독이 아니라 **선수**라서, 내가 정하는 건 훈련·경기 중 결정 순간·카드 덱·계약·돈 쓰기이고, 팀 성적과 출전은 감독 신뢰도·폼·피로에 달려 있어요. 싱글 플레이 웹 게임(PWA, 오프라인 가능), 한국어.

**핵심 플레이 고리** (하루 단위 달력이 돌아감):

```
 ┌─ 훈련(프리셋·하루 훈련·생활) ─→ 경기 준비(상대 분석·덱·전술·직접/자동) ─→ 경기(재생 또는 결정 순간 직접 플레이)
 │                                                                                         │
 │   ← 카드/덱(카드 선택권·상점 팩) ← 결과(평점·보상·레벨업·클립·유니폼 교환) ←──────────┘
 │
 └─ 사이사이: 인박스 이벤트(선택형) · 감독 면담 · 이적 소식 · 재정(연봉·생활·투자) · 대표팀 소집 · 개인 시상
      시즌 끝: 시즌 요약 → 이적 제안/재계약 → (챕터 리뷰) → 다음 시즌 … → 은퇴 → 커리어 요약·명예의 전당
```

**화면 크기 기준**: 폰 세로 **390×844 다크**(1순위) + PC **1280×800 다크**. 가로 폰은 그리지 않아요(지금 코드에 가로 폰 레일 독이 있지만 이번 범위 밖). 라이트 테마는 토큰만 있고 설정에 켜는 스위치가 없음 → 라이트를 계속 둘지는 사용자 결정(아래 D2).

**산출물 형식**: 화면 카드(S번호)마다 **폰 + PC 한 장씩, 카드에 적힌 상태마다**. 디자인 시스템(토큰·컴포넌트 README·bundle.css/js)과 화면별 png + html. 지난 묶음 `player-one-design-b/` 구조(HANDOFF.md · index.json · design-system/ · screens/png·html·source)를 그대로 쓰되 **새 번호 체계 S01~S40** + 상태 접미어(예 `S07-b_홈-비시즌`)로 주세요. 옛 번호(1~259)는 HANDOFF 표에 "S로 대체"로 적어 주세요.

**우선순위 3단계**:

## 2. 디자인 시스템 — "그대로 유지"(①)와 "새로 제안"(②)

### ① 지금 B 테마 규칙 (유지할 경우 이대로)

- **색**(다크, `src/ui/design/tokens.css`): 바탕 `surface-0 #16171b` / `surface-1 #1d1f25` / `surface-2 #23252c` / `surface-3 #2c2f37`, 카드 `#121317`, 선 `#2a2c33`, 글 `ink #f3f4f6` · `ink-muted #a3a8b2` · `ink-faint #8b909b`, **브랜드 라임 `#d6ff3c`**(면으로 크게 한 번), **내 선수 시안 `#5ee0ff`**(내 선수 표식에만), 성공 `#4ade80` · 실패 `#ff7a6b` · 경고 `#ffb020` · 부상 `#ff7ab8`, 원정 `#ff8a3d`. 희귀도 일반 `#a9aeb7` / 희귀 라임 / 에픽 `#b69cff` / 전설 `#ffd23f`. 평점 5단 색(빨강→주황→노랑→연두→시안). 선택지 안전 시안 / 균형 라임 / 도박 주황. 라이트 토큰 값은 같은 파일 light 블록(쓰는 곳 없음).
- **모양**: 버튼·세그먼트 탭·뒤로·독 [다음] 키·진행 칸은 **꺾인 사각형**(평행사변형 clip-path 8px). 모서리 2·3·4·6px, 둥근 알약 없음. 칩은 `skewX(-8~-10deg)`.
- **글꼴**: 숫자 = **Barlow Condensed 이탤릭**(PO Display, 600~800) · 제목·큰 버튼·독 진행 칸·선수 이름 = **Black Han Sans**(PO Head) · 본문 = **Pretendard**.
- **머리말(HeroPanel)**: 어두운 바탕 + 오른쪽 라임 사선 면 2겹 + 아래 2px 라임 줄. 큰 숫자 하나(OVR·잔고 등). **미페 머리말** = 투명 배경 선수 사진(또는 네모 사진)을 왼쪽에, 뒤에 라임 등번호, 아래 이름·소속·칩, 오른쪽 아래 OVR. 홈 430px · compact 290px.
- **원칙**: 라임은 한 화면에 한 번 크게 · 발광·그라데이션·금박 없음(팩 개봉 연출만 예외) · 숫자는 문장으로 설명("성공 확률이 **+12%p** 올라가요") · 확률·보상 숨기지 않음 · 해요체.
- **경기장은 항상 가로**(왼쪽 → 오른쪽 공격). 세로 피치 설정은 있지만 기본은 가로.
- 컴포넌트 45종 + B 변형(README `docs/design/player-one-design-b/design-system/README.md`).

### ② 새로 제안할 경우 (허용 범위)

- 바꿔도 되는 것: 색 체계(라임·시안 역할 포함), 글꼴, 모양 언어(꺾인 사각형), 머리말 형식, 독 형식, 정보 밀도 규칙.
- **바꾸면 안 되는 것**(D1과 무관하게 고정): 한국어 해요체 · 다크 1순위 · 폰 세로 390 기준 · **피치는 가로** · 확률·보상 공개 · 내 선수 강조 색은 한 가지로 일관 · 터치 영역 44px 이상 · 본문 14px 이상(보조 12px 이상) · 대비 4.5:1 이상.
- 제안하면 토큰 JSON(다크/라이트) + 컴포넌트 README(props) + bundle 구현까지 주세요(지금처럼 코드가 그대로 가져다 씀).
