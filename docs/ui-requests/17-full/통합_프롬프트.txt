## 1. 한 쪽 요약

**게임 한 줄**: 축구 선수 **한 명**의 커리어 — 17세 유망주(또는 실제 2018-19 선수·레전드·커스텀 선수)로 데뷔해 은퇴까지. 감독이 아니라 **선수**라서, 내가 정하는 건 훈련·경기 중 결정 순간·카드 덱·계약·돈 쓰기이고, 팀 성적과 출전은 감독 신뢰도·폼·피로에 달려 있어요. 싱글 플레이 웹 게임(PWA, 오프라인 가능), 한국어.

**핵심 플레이 고리** (하루 단위 달력이 돌아감):

```
 ┌─ 훈련(프리셋·하루 훈련·생활) ─→ 경기 준비(상대 분석·덱·전술·직접/자동) ─→ 경기(재생 또는 결정 순간 직접 플레이)
 │                                                                                         │
 │   ← 카드/덱(카드 선택권·상점 팩) ← 결과(평점·보상·레벨업·클립·유니폼 교환) ←──────────┘
 │
 └─ 사이사이: 인박스 이벤트(선택형) · 감독 면담 · 이적 소식 · 재정(연봉·생활·투자) · 대표팀 소집 · 개인 시상
      시즌 끝: 시즌 요약 → 이적 제안/재계약 → (챕터 리뷰) → 다음 시즌 … → 은퇴 → 커리어 요약·명예의 전당
```

**화면 크기 기준**: 폰 세로 **390×844 다크**(1순위) + PC **1280×800 다크**. 가로 폰은 그리지 않아요(지금 코드에 가로 폰 레일 독이 있지만 이번 범위 밖). 라이트 테마는 토큰만 있고 설정에 켜는 스위치가 없음 → 라이트를 계속 둘지는 사용자 결정(아래 D2).

**산출물 형식**: 화면 카드(S번호)마다 **폰 + PC 한 장씩, 카드에 적힌 상태마다**. 디자인 시스템(토큰·컴포넌트 README·bundle.css/js)과 화면별 png + html. 지난 묶음 `player-one-design-b/` 구조(HANDOFF.md · index.json · design-system/ · screens/png·html·source)를 그대로 쓰되 **새 번호 체계 S01~S40** + 상태 접미어(예 `S07-b_홈-비시즌`)로 주세요. 옛 번호(1~259)는 HANDOFF 표에 "S로 대체"로 적어 주세요.

**우선순위 3단계**:

> 캡처 번호: `P###` = `captures/phone/###_*.png`, `C###` = `captures/pc/###_*.png`. 캡처 세이브: 실제 선수 모하메드 살라(리버풀, 2018-19 10월·3월·비시즌·2시즌차 9월), 생성 선수(전체 랜덤 17세), 가상 유망주 김민준(허더즈필드, 부상 중), 세르히오 아구에로(31세 은퇴).
> 공통 문제(모든 화면): 글자 9~11px 다수, 머리말이 첫 화면의 30~50%, 오른쪽 위 큰 글자가 라임 사선 면에 걸려 잘림 — 화면마다 반복해 적지 않고 처음 나온 곳에만 적어요.
