| 단계 | 큰 것(새 화면·큰 패널) | 작은 변형 |
|---|---|---|
| C.45 (34단계 신체·양발·커스텀·도트 아이콘) | 4 — 커스텀 생성 화면, 설정 → 경기 아이콘, 선수 화면 신체·양발·태그 칸, 홈 1군 테스트 띠 | 5 — 랜덤 새 게임 신체·태그 줄, 선수 화면 경기 아이콘 카드, 이적 제안 "친정 · 유스 구단" 칩·자유계약 안내, 경기 화면 캐릭터(도트 + 등번호 띠), 커리어 태그 소식 |

| C.47 (34c 레전드 팩·태그 효과) | 1 — 실제 선수 목록 "레전드" 묶음 | 5 — 레전드 팩 끔/켬 줄, 선수 화면 태그 줄 대표 4 + 전체 보기, 홈 태그 알림 한 줄, 월드 레전드 목록, 태그 소식 새 이름 |

### 대표 문제 (폰 390×844)
1. **새 게임 화면이 너무 길다.** 커스텀 5,785px(포인트 띠·이름·나이·포지션 12칸·신체·주발/약발·국적·외모·도트 머리·태그 장점 9줄·태그 단점 8줄·능력치 배분 바둑판·시작 소속·난이도·레전드 팩·시드가 한 줄로 쌓임), 실제 선수 + 레전드 10,331px(레전드 107줄이 검색·필터 없이 이어짐). 단계(스텝) 나누기나 섹션 접기, 목록 검색이 필요하다. (`phone/X03_새게임-커스텀-전체.png`, `X02_새게임-실제선수·레전드-전체.png`)
2. **설정 화면이 4,793px로 다시 길어졌다**(5차 3,335px). 경기 아이콘·카드 이미지 두 섹션이 각각 검색 + 목록을 가져 한 화면에 목록이 4개(선수 이름·경기 아이콘·페이스온·카드 이미지)다. 5차 디자인의 설정(66)에 이 두 섹션 자리를 정해야 한다. (`phone/X06_설정-전체.png`)
3. **선수 화면 4,596px**(5차 3,994px). 신체·양발·태그 칸, 경기 아이콘 카드, 몸값·바이아웃이 더해졌다. 5차 디자인의 탭 구성(93~96)에 들어갈 자리가 없다. (`phone/X05_선수화면-전체.png`)
4. **레전드 칩이 긴 이름에서 줄바꿈**된다(C.47 코드 세션 메모). (`phone/C47_2_실제선수-레전드-묶음.png`)
5. **태그 표시 규칙이 없다**: 생성 태그(영구/해제형)·커리어 태그·플레이 태그·스토리 태그가 칩 하나로 섞여 있고, 해제형·효과 슬롯 0(스토리)의 구분이 글자뿐이다. (`phone/C47_3_선수화면-태그줄.png`, `X03` 태그 영역)
6. **카드 그림 칸**: 그림이 있는 카드와 기본 장면 카드가 덱에 섞이면 톤이 다르다. 그림 없는 카드의 기본 장면 규칙(또는 공통 플레이스홀더)이 필요하다. (`phone/C48_2_덱편집-그림-섞인-mini.png`)
7. **도트 유니폼이 비슷해 보이는 경기**(뉴캐슬 흑백 줄 vs 사우샘프턴 원정 검정). 표시 쪽에서 구분 보조(등번호 띠 색 등)가 필요한지. (`phone/C45_20_경기화면-캐릭터-뉴캐슬-사우샘프턴.png`)

## ② 필요한 업데이트 내용 (화면별)

표기: **목적 / 보여 줄 데이터 / 상태 / 캡처 / 컴포넌트**. 컴포넌트 이름은 디자인 묶음 44종.

### A. 큰 것 (7)

**A1. 새 게임 → 커스텀 생성** (C.45 ①, 2차에서 "장단점" → "태그 · 장점/단점")
- 목적: 직접 선수를 만든다. 기본 능력치 40 + 배분 포인트 100P(나이·태그에 따라 늘고 줆).
- 데이터: 위 고정 **배분 포인트 띠**(남은 nP, 사용 내역 "나이 +n · 태그 −n"), 이름, 나이 15~23 스테퍼(포인트가 같이 바뀜), 포지션 12칸(포지션별 시작 OVR), 신체(키·몸무게 스테퍼, BMI, 키를 올리면 "속도 상한 ↓" 안내), 주발(오른발/왼발)·약발 1~5 칩(5 = 양발), 국적 선택, 외모군 칩 5·도트 머리 칩, **태그 · 장점 / 단점** 목록(각 줄: 이름·효과 설명·[영구 nP]/[해제형 mP] 두 버튼, 단점은 포인트 +), 능력치 배분 바둑판(AttrTile 편집 상태 + [자동 배분(OVR 우선)]·[초기화]), **시작 소속**(15~18세 유스 구단 = 1군 테스트 / 19~23세 소속팀 고르기 / 소속팀 없음 = 영입 제안, 구단 칩 목록), 난이도, 레전드 팩 끔/켬, 시드, [시작].
- 상태: 포인트 남음/0/초과(시작 막힘), 태그 영구·해제형 선택, 나이에 따라 시작 소속 선택지가 바뀜.
- 캡처: `phone/X03_새게임-커스텀-전체.png`, `C45_02~C45_07`, PC `pc/X03`
- 컴포넌트: Tabs(랜덤/커스텀/실제 선수) + OptionRow + AttrTile + TextField. **스테퍼**(− 값 +)와 **포인트 띠**는 새로 필요. 스텝 나누기(예: 기본 → 신체·외모 → 태그 → 능력치 → 시작 소속) 또는 섹션 접기 제안.

**A2. 설정 → 경기 아이콘** (C.45 ②)
- 목적: 경기 화면 "캐릭터" 보기의 도트 아이콘을 바꾼다. 아무 선수의 인물, 구단·대표팀 유니폼.
- 데이터: [선수 | 유니폼] 탭. 선수 탭 = 검색 + 팀 거르기, 목록(지금 도트 아이콘·이름·팀), 고른 선수의 **인물 14종 격자**(16px 도트, 정수배 확대). 유니폼 탭 = 구단·대표팀 목록, **홈/원정 32종 격자**. 고른 것 강조, [기본으로].
- 상태: 기본 / 바꿈 / 경기 중 잠금.
- 캡처: `phone/C45_12_설정-경기아이콘-선수.png`, `C45_13_…선수 고르기.png`, `C45_14_…유니폼.png`, `X06` 경기 아이콘 섹션
- 컴포넌트: Tabs + TextField + OptionRow. **도트 격자 타일**(PixelTile) 새로 필요(이미지 렌더링 pixelated).

**A3. 선수 화면 → 신체·양발·태그 칸** (C.45 ③ + C.47 태그 줄)
- 목적: 선수 몸과 태그를 한눈에.
- 데이터: 5칸(등번호·키·몸무게·주발·약발 ★1~5), [약발 +1 · 50P](포인트 부족이면 회색), **태그 줄 대표 4개**(커리어·플레이 → 장점 → 단점, 최근 순) + [전체 보기](시트: 생성 태그(영구/해제형 표시·해제 조건)·커리어 태그(그 구단에서만 효과)·플레이 태그(노익장·늦게 핀 꽃·빅매치 체질)·스토리 태그(효과 없음) 묶음), 유스 출신 줄.
- 상태: 태그 0개 / 4개 이하 / 많음, 해제형 해제됨, 약발 5(양발잡이).
- 캡처: `phone/C45_09_선수화면-신체·약발·장단점.png`, `C47_3_선수화면-태그줄.png`, `X05_선수화면-전체.png`
- 컴포넌트: StatChip + Button + BottomSheet. **TagChip**(종류 4색 규칙 + 해제형·효과 없음 표시) 새로 필요. 5차 선수 화면 탭(93~96) 중 어디에 둘지 정해 주세요.
