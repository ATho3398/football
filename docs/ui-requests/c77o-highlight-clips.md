# UI 요청 초안 — C.77o 경기 후 하이라이트 클립 (P단계 1차, 24.6)

> UI 세션(UI_5)이 받을 형식의 초안. C.77o 는 기존 디자인 토큰·컴포넌트로 **최소 구현**만 했다. 아래 화면에 새 디자인이 필요하다.
> 캡처: `docs/c77o-check/` (폰 390×844 · PC 1280×800). 새 화면·큰 패널 집계: **큰 1(경기 결과 · 하이라이트 클립 패널) + 작은 1(클립 재생 상태)**.

## 1. 왜 필요한가
- 24.6: 경기가 끝나면 하이라이트 3개(골 · 결정적 장면 · 내 최고 평점 순간)를 이벤트 앞뒤 8초 프레임으로 **세이브에 남기고** 경기 후 화면에서 다시 본다. 최근 10경기 보관이라 세이브를 불러온 뒤에도 볼 수 있다(기존 [하이라이트 다시보기]는 방금 경기에서만).
- 지금은 "내 결정 기록" 줄(`dec-row`)을 빌려 썼다 — 결정 기록과 생김새가 같아 구분이 약하고, 클립 종류(골/기회/내 순간)의 색·아이콘이 없다.

## 2. 화면별 내용

### 2-1. 경기 결과 · 하이라이트 클립 패널 (큰 것)
- 위치: 경기 결과 화면, [하이라이트 다시보기] 패널 바로 아래(PC 2단이면 왼쪽 칸).
- 데이터: 클립 0~3개. 클립마다 종류(`goal` 골 · `chance` 결정적 장면 · `best` 내 최고 순간), 경기 분(예 39'), 한 줄(이벤트 피드 문구: "골! 해리 케인 (토트넘) · 도움 나 — 3 : 0", "슈팅 (유효) …"), 팀(우리/상대 — 실점 골이면 상대).
- 동작: 줄을 누르면 그 클립 하나 재생, [n개 이어 보기]는 모두 차례로(사이 1초 전환). 재생이 끝나거나 건너뛰면 결과 화면으로.
- 상태: 클립 0개면 패널 없음. 1개면 [이어 보기] 없음. 실점 골·상대 기회는 상대 색. 지금 줄 길이: 긴 골 문구가 두 줄로 넘친다(폰).
- 요청: 클립 카드(종류 배지·아이콘, 분, 한 줄, 재생 표시), 가능하면 클립의 첫 프레임 썸네일 자리(피치 미니 그림 — 데이터는 있음, 렌더는 P2).

### 2-2. 경기 화면 · 클립 재생 상태 (작은 것)
- 기존 경기 재생 화면(하이라이트 모드)을 그대로 쓴다. 다른 점: [여기서부터 실시간] 버튼 숨김(클립 밖 프레임이 없다), 아래 패널 제목 "하이라이트 클립 · n개 · 클립당 약 16초(앞뒤 8초)", 장면 칸은 클립 수만큼.
- 요청: 클립 재생임을 알리는 머리 줄(예 "클립 2/3 · 골"), 장면 칸 라벨(골/기회/내 순간) 색.

## 3. Claude Design 프롬프트 (초안 — UI 세션이 통합본에 합친다)

```
[경기 결과 · 하이라이트 클립] 경기 결과 화면에 "하이라이트 클립" 패널을 디자인해 주세요(B 테마, 폰 390×844 · PC 1280×800 2단 왼쪽 칸).
- 위치: [하이라이트 다시보기] 패널 바로 아래.
- 클립 0~3개: 종류 3가지 — 골(우리 골 = 라임, 실점 = 주황), 결정적 장면(슈팅·기회), 내 최고 순간(내 선수 강조색 --mine). 각 카드에 종류 배지+아이콘, 경기 분(39'), 한 줄 문구(최대 2줄, 넘치면 말줄임), 재생 아이콘. 첫 프레임 미니 피치 썸네일 자리(선택).
- 아래에 보조 버튼 [3개 이어 보기] (클립 2개 이상일 때만).
- 상태: 클립 1개, 3개, 긴 문구(“골! 해리 케인 (토트넘 홋스퍼) · 도움 손흥민 — 3 : 0”).
[경기 화면 · 클립 재생] 기존 경기 재생 화면(하이라이트 모드)의 클립 재생 상태: 머리 줄 "클립 2/3 · 골", [여기서부터 실시간] 없음, 아래 장면 칸 라벨 골/기회/내 순간 색 구분.
```
