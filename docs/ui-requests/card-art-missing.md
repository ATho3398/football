# 카드 그림이 기본 장면으로 남는 원인 (2026-10-19, UI_3)

- 사용자 질문(03:00): "카드 줬는데 아직 기본 이미지인 것(리셋 등) — 등급 안 맞아서?"
- **원인: 등급 문제가 아니라 그림 파일이 레포에 없다.** 게임은 카드 id로만 그림을 찾는다(`src/ui/cardArt.ts` `CARD_ART_FILES` → `public/cards/art/<id>.webp`, 시그니처 `sig-<역할>` → `<역할>.webp`). 희귀도는 그림 찾기에 쓰이지 않는다(틀 색만).
- 레포에 들어온 카드 그림은 **BATCH 03 한 번뿐**(2026-10-17 22:40, 시그니처 16장 + 엘라스티코 = 17장, `docs/design/incoming/card-art/batch03/`, C.48 적용). 
- 그림 없는 카드 **59장**: 일반 카드 44장(카드 45장 중 엘라스티코만 있음 — 리셋·템포 조절·침착·전진 운반 등 전부) + 시그니처 15장(정통 윙어·윙포워드·크랙형 윙어·라움도이터·와이드 미드·포처·하프백·풀백 4종·스토퍼·볼 플레잉 CB·커버 CB·리베로). BATCH 01·02·남은 시그니처는 UI_1·UI_2·UI_3 어느 세션에도 온 적이 없다(handoff "대기").
- 그림 찾기·표시 코드는 덱·경기 준비·결정 순간 패·카드 획득·카드 상세 모두 같은 함수(`gameCardData` → `cardArtOf` → `cardArtUrl`)를 써서 문제없음. 게임 안 설정 → 카드 이미지로 직접 올린 그림도 같은 길로 보인다.
- 해결: ① 카드 그림 세션에 남은 59장 요청(`card-art-remaining-prompt.txt`, 형식 = 카드 id 이름 파일·3:2·틀/글자 없음) → ② 받으면 UI 세션이 `public/cards/art/`용으로 잘라 `docs/design/incoming/card-art/<묶음>/`에 넣고 → ③ 코드 세션이 `CARD_ART_FILES`에 id 추가(작은 패치). 이미 다른 곳에 그려 둔 그림이 있으면 그 zip을 이 세션에 주면 ②부터.

## 갱신 (2026-10-19 03:10 KST) — 사용자가 준 그림 위치값 61장

- 사용자가 카드 그림 세션의 **위치값 표 61장**(정식 = full, 간략 = mini 각각 x·y·zoom, 일부 `반전`·`기울`)을 줬다 → `docs/ui-requests/card-art-positions.json`(카드 id별 `{name, full, mini}`).
- 뜻: 그림은 **61장이 이미 있다**(일반 41 + 시그니처 20: BATCH 03 17장 + 바이라인 컷백·빈 공간 원터치·측면 복귀 태클·원터치 마무리). **하지만 그림 파일은 이 레포에 없다**(BATCH 03 17장뿐) → 게임은 리셋 등 44장을 기본 장면으로 그린다. 원인은 여전히 등급이 아니라 **파일 미도착**.
- 위치값이 정식·간략 모두 기본값(x0 y0 z1)인 6장: 리셋 · 니어 포스트 강슛 · 오프사이드 라인 타기 · 몸으로 막기 · 철벽 수비 · 내려와서 연계 — 위치를 안 맞췄거나 그림 세션에서도 그림이 비어 있는지 확인 필요.
- **그림이 아예 없는 카드 15장**: 시그니처 11(윙포워드·크랙형 윙어·하프백·풀백 4종·컴플리트 윙백·스토퍼·볼 플레잉 CB·커버 CB·리베로) + 일반 4(오프사이드 트랩 지휘·지시 이행·독단·감독의 신뢰) → `card-art-remaining-prompt.txt`를 15장으로 줄임.

### 코드 쪽에 필요한 것 (작은 패치)
1. **그림 파일 61장**을 받아 `public/cards/art/<파일>.webp`(시그니처는 역할 id)로 넣고 `CARD_ART_FILES`에 추가 — 파일은 사용자가 이 세션에 주면 UI_3가 이름 맞춰 `docs/design/incoming/card-art/<묶음>/`에 넣는다.
2. **기본 위치값**: 지금 `ArtPos`는 카드당 하나(x·y·zoom)이고 기본 그림엔 위치가 없다. 위치표를 쓰려면 카드별 **기본 위치를 크기별로**(`full` = 카드 상세·획득·덱 큰 카드, `mini` = 덱 칸·패·경기 준비 줄) 두고, `flip`(좌우 반전, `scaleX(-1)`)·`rotate`(도, 롱패스 전환 간략 −16) 지원. 우선순위: 사용자 위치(설정 → 카드 이미지) > 기본 위치표 > 가운데.
3. 위치 단위는 지금 `artStyle`과 같은 뜻(x 오른쪽 %, y 위로 %, zoom 1~4)인지 그림 세션 기준과 한 번 대조(캡처 1장씩, 감아차기·롱패스 전환·프리킥 크로스).

## 해결 (2026-10-19 03:12 KST)
- 그림 61장 도착 → `docs/design/incoming/card-art/set61/` + `card-art.json`(위치값 포함, 앞의 `card-art-positions.json`은 이것으로 대체·삭제). 적용 명세 `card-art-set61-apply.md`. 남은 그림 없는 카드 15장.
