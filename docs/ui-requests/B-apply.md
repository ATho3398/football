## 1. 넣는 방법

1. **층으로 넣는다**: `src/ui/design/`에 B 글꼴 4개 추가(Barlow 3 + Black Han Sans). B 토큰 차이(글꼴 2·모서리 6)와 B 블록 CSS를 **`[data-skin="b"]` 아래로** 묶어 `src/ui/design/skin-b.css` 하나로 둔다(A 파일은 손대지 않음). `<html data-skin="b">`가 기본. 속성을 빼면 A로 돌아간다.
2. **설정 → 꾸미기에 "화면 스타일 A · B" 한 줄**(추천, 기본 B). 세이브가 아니라 기기 설정(localStorage)이면 `SAVE_FORMAT_VERSION` 변경 없음.
3. B 블록 선택자 47개 중 **28개는 코드에 이미 있다**(`po-btn*` `po-chip` `po-hero*`(face 제외) `po-tab*` `po-section__*` `po-meter__*` `po-banner` `po-num` `po-icon`) → CSS만으로 바로 바뀜. **19개는 코드에 없다**: 독(`po-dock*` 9개 — 코드 독은 `dock-*` 클래스), 미페 머리말(`po-hero--face` `__kit` `__face` `__slab` `__line` `__who` `__name` `__unit`), `po-hero--text`, `po-attr__val`, `po-day__date`, `po-offer__actions`. 이것들은 코드 클래스에 맞춰 옮겨 쓰거나 해당 컴포넌트를 B 구조로 바꾼다.
4. **Poppins**: B에서는 안 씀. A 전환을 남기면 그대로 두고, 아니면 뺀다.
5. **모서리 값이 박힌 곳**: `style.css`에 `border-radius` 90곳(그중 999px/50%/pill 13곳)이 토큰이 아니라 숫자다. B에서 둥근 것과 각진 것이 섞이지 않게 토큰(`--radius-*`)으로 바꾸거나 `[data-skin="b"]` 덮어쓰기를 둔다. 동그라미여야 하는 것(아바타·점·라디오)은 그대로.

## 2. 미페 머리말 (`HeroPanel face`) — 홈 86 · 선수 93/134/136 · 1군 테스트 132

- 쓰는 곳: **내 선수** 홈(풀 430px)과 선수 화면(compact 290px). PC 홈(120)은 디자인대로 **일반 B 머리말**(미페 없음).
- **사진 고르기**: 페이스온(사용자 업로드) > `public/facepack`(레포 사진) > 없음. 실제 선수가 아니어도 페이스온이 있으면 쓴다.
- **사진 종류별 모양(사용자 결정)**:
  - 투명 미페(누끼): 디자인 그대로 — `.po-hero__face` 380×380(compact 250) `object-fit: contain; object-position: bottom`, 색 처리 없음, 뒤 등번호·아래 사선 검정 면이 몸 아래를 덮음.
  - **투명이 아닌 사진(jpg, 배경 있는 png — 지금 facepack 150장 전부, 128×128 위키백과 사진)**: **네모 사진 그대로 같은 자리에**. 같은 위치·같은 아래 정렬, 정사각형 상자 `object-fit: cover`, 모서리는 B 토큰(`radius-md` 4px). 사선 검정 면·라임 줄은 그대로 사진 아래쪽을 덮는다. 128px 사진은 380px에서 흐릴 수 있음 — 그대로 두고 확인 캡처로 보고(더 큰 사진 팩은 나중 일).
  - 투명 판정: 이미지 알파로 자동 판정하지 않는다(facepack png도 RGBA라 틀림). **페이스온 업로드에 "배경 없는 사진" 표시**(업로드 시 켬/끔, 기본 끔) 또는 manifest `cutout: true`가 있을 때만 투명 미페로 본다. 나머지는 모두 네모.
  - 사진 없음(생성 선수 기본 등): **일반 B 머리말**(사선 라임 면) — B 핸드오프 "결정 필요" 항목의 UI_3 추천. 사용자가 다르게 정하면 바꿈.
- **등번호 `kit`**: 내 선수 등번호. 두 자리면 `is-two`(작게). 번호 없으면 등번호 숨김.
- **긴 이름 = 글자 크기 줄이기(사용자 결정)**: 이름 칸 폭(폰 390 기준 `left 16px ~ right 130px` = 244px)에 맞을 때까지 줄인다. 풀 50px → **최소 24px**, compact 36px → **최소 24px**. 측정은 `canvas.measureText`(PO Head 로드 뒤, `document.fonts.ready`) 또는 한 글자 폭 근사. 최소에서도 넘치면 그때만 말줄임.
  - 실측(실제 선수 + 레전드 148명, Black Han Sans): 50px 그대로면 **88명(59%)** 넘침, 36px면 26명. 최소 24px이면 **0명**(가장 긴 "바스티안 슈바인슈타이거"가 약 25.8px에서 맞음). 손흥민 50px = 125px.
  - 이름은 **전체 이름**(`nameKo`/생성 이름). 짧은 이름으로 바꾸지 않음.
- 소속 줄(`eyebrow`)·칩·OVR(`value`+`unit`)은 디자인 위치 그대로.
