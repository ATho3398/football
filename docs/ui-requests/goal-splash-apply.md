## 언제
- 경기 화면(직접·보기 모드, 실시간 재생)에서 **우리 팀 골**이 들어간 순간(이벤트 피드에 골이 찍히는 프레임). 하이라이트 다시보기·클립 재생(C.77o)에서도 같은 골이면 나온다.
- 실점 골에는 안 나온다(지금의 실점 표시 그대로). 빠른 진행·건너뛰기 중에는 안 나온다.
- 결정 순간 결과 화면(`po-splash--goal`)과 겹치면 결정 결과가 먼저, 끝난 뒤 이 연출(또는 결정 결과 골이면 이 연출로 대신 — 코드 세션 판단, 한 번만 나오게).

## 움직임 (약 1.6초, 탭하면 바로 사라짐)
1. **날아오기 0~280ms**: 화면 왼쪽 밖(`translateX(-110vw)`)에서 가운데로, 살짝 기울어진 채(-8°) 들어와 0°로. 이징 `cubic-bezier(.2,.9,.25,1.15)`(끝에서 살짝 지나쳤다 돌아옴). 들어오는 동안 가로 모션 블러 느낌(이전 위치 잔상 2개, 투명도 .35·.15) 또는 `filter: blur(4px)→0`.
2. **멈춤·흔들 280~1200ms**: 가운데에서 크기 1.0 → 1.06 → 1.0 펄스 1번(200ms), 화면 살짝 흔들기(피치 캔버스 3px, 150ms). 뒤 배경은 피치 위 검정 30% 막(가볍게).
3. **빠져나가기 1200~1600ms**: 오른쪽으로 날아가며(`translateX(110vw)`, 기울기 +6°) 투명도 1→0. 이징 `cubic-bezier(.5,0,.9,.4)`.
- 크기: 폰 폭의 92%(최대 520px), PC 피치 영역 폭의 55%(최대 720px). 세로는 피치 가운데.
- 경기 재생은 연출 동안 그대로 흐른다(멈추지 않음) — 지금 골 뒤 재개 대기가 있으면 그 시간 안에 끝남.
- `prefers-reduced-motion`이면 날아오기 없이 가운데에서 페이드 인·아웃(600ms).
- 설정: 기존 연출 설정(C.76o '팩 개봉 연출 전체/짧게/끔' 줄 옆)에 "골 연출 [켬|끔]" 한 줄 — 끔이면 안 나옴. 기본 켬.

## 바꿀 곳(예상)
- 경기 화면 오버레이 레이어(피치 캔버스 위 DOM 한 겹, `pointer-events` 탭으로 닫기만).
- 골 이벤트 훅(경기 재생 프레임에서 우리 팀 골 감지) — 엔진 무수정, 화면만. ENGINE·BALANCE·SAVE 버전 그대로(설정 한 줄을 세이브 설정에 넣으면 SAVE_FORMAT_VERSION 규칙 따름).

## 확인 캡처 기준
- 폰 390×844 · PC 1280×800, 골 장면 3프레임(날아오는 중 140ms · 가운데 700ms · 빠지는 중 1400ms) + 실점 골에 안 나옴 1장 + 설정 줄 1장. 가로 넘침 0(오버레이가 페이지 가로 스크롤을 만들지 않게 `overflow:hidden`).
