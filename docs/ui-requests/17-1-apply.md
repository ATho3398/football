1. **D1 B 테마 유지 · D2 다크만(라이트 186~188 안 그림) · D3 폰 독 5칸([다음] 정가운데) · D4 홈 탭 3개 [오늘][시즌][경쟁] + 접은 카드(탭당 폰 1,600px 이하).**
