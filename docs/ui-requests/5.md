## ① 왜 업데이트가 필요한지

4차 요청(2026-10-15) 뒤 C.35~C.44a 11개 단계에서 화면이 디자인 없이 컴포넌트 조합으로 만들어졌다. 지금 게임 화면(시트·패널 포함) 35개를 디자인 묶음과 대조한 결과:

| 분류 | 화면 수 | 화면 |
|---|---|---|
| **디자인 없음** | 16 | 하단 독·더보기, 자동 진행 시트, 자동 진행 레이어·끝 요약, 새 기능 안내, 설정 화면, 페이스온 편집, 선수 이름 편집, 경기 화면 보기 시트, 결정 결과 띠, 카드 장면 시트, 카드 획득 3택1, 이적 제안, 재계약, 이적 요청(선수 화면 계약 칸), 이적 소식(월드·시즌 상세), 경기 기록(선수 화면) |
| **기획이 바뀜**(디자인은 있으나 구조가 바뀜) | 9 | 홈, 결정 순간 패널, 경기 화면(세로 피치·이름 라벨), 선수 상세, 훈련·일정, 하루 훈련 시트, 시즌 종료(요약 + 상세 6탭), 포인트 찍기(1~20), 새 게임(포지션별 OVR·바둑판) |
| **디자인과 달라짐**(같은 목적, 배치·요소 차이) | 6 | 덱 편집, 경기 결과, 다시 보기(리플레이), 월드(순위·리그 스타·득점 순위), 세이브, PC 레이아웃 전체 |
| 디자인대로(요청 안 함) | 4 | 타이틀, 건너뛰기 확인, 카드 상세, 전술(큰 차이 없음) |

조건(디자인 없는 새 화면 6개 이상 / 그런 단계 3개 이상)을 둘 다 크게 넘었다.

### 대표 문제 (폰 390×844)
1. **결정 순간에서 패 카드·[맡기기]가 첫 화면에 안 보인다.** 세로 피치가 화면 위 55%를 쓰고 선택지 3개가 나머지를 채워, 카드 줄과 버튼이 독 아래로 밀린다. PC는 오른쪽 패널에 다 보인다. (`phone/K03_결정순간-기본.png` ↔ `pc/K03_결정순간-기본.png`)
2. **세로 피치에서 선수가 몰리면 이름 라벨이 서로 겹쳐 읽을 수 없다**(박스 근처 6~8명). (`phone/K03_결정순간-기본.png`, `K06_결정결과-재생중.png`)
3. **재계약 화면 머리말 "계약 만료"가 넘쳐서** 뒤로 버튼·제목·부제를 덮는다(HeroPanel 큰 숫자 자리에 긴 글자). (`phone/O02_재계약.png`)
4. **훈련 주간 계획 7칸**: 칸 폭 약 40px에 날짜·훈련 이름·"고정/오늘"이 들어가 글씨가 작고 빽빽하다. (`phone/G01_일정훈련-위.png`)
5. **포인트 찍기**: 큰 머리말 + OVR 줄 + 설명 + 아래 고정 [초기화][확정] 바 때문에 첫 화면에서 능력치 박스가 한 줄만 보인다. (`phone/P01_포인트찍기-위.png`)
6. **너무 긴 화면**: 선수 화면 3,994px(폰 4.7장), 설정 3,335px, 새 게임 2,761px, 홈 2,669px, 경기 결과 2,595px. 섹션이 위아래로 쌓이기만 해서 원하는 정보를 찾기 어렵다. (`phone/D02_선수-전체.png`, `C02_설정-전체.png`)
7. **큰 머리말(HeroPanel)이 의미 없이 반복**: 덱 "08/14", 설정 "설정", 월드 "17위"가 탭을 바꿔도 화면 위 1/3을 차지한다. (`phone/E01_덱-위.png`, `C01_설정-위.png`, `H01~H06`)
8. **탭이 넘친다**: 시즌 상세 탭 6개(경기별·월별·포지션별·리그 시상·이적 소식·성장/위상)가 한 줄을 넘어 "이적 :"처럼 잘린다. (`phone/N03_시즌상세-경기별.png`)
9. (정정 2026-10-18) 결정 순간은 지금도 선택 → [확정] 2단계다. 폰에서 [확정]이 화면 밖에 있어 1번 문제와 같은 원인.
10. **PC(1280)**: 홈·선수·덱 등 대부분이 가운데 1열(약 600px)이고 양옆이 비어 있다. 독은 9칸. 2열은 결정 순간만 쓴다. (`pc/B01_홈-기본.png`, `pc/D01_선수-위.png`)

## ② 필요한 업데이트 내용 (화면별)

표기: **목적 / 보여 줄 데이터 / 상태·빈 상태 / 캡처 / 기존 컴포넌트로 되는지**. 컴포넌트 이름은 디자인 묶음 38종(`design-system/components`).

### A. 디자인 없음 (16)

**A1. 하단 독 + 더보기 시트** (C.44)
- 목적: 게임 중 모든 화면 아래 고정 메뉴. 가운데 **진행** 칸이 그때 할 일을 보여 준다.
- 데이터: 폰 6칸 = 홈 / 진행([계속]·[경기]·[경기 중]·[답하기]·[시즌 요약], 배지 숫자) / 선수(포인트 배지 "35") / 훈련·일정 / 월드 / 더보기(덱·전술·설정·저장). PC 9칸 = 전부.
- 상태: 진행 칸 5종, 전술 잠김(자물쇠 + "3경기 뒤에 열려요"), 경기 중(다른 화면 "경기 중 · 돌아가기" 띠 + 행동 잠금), 배지 있음/없음.
- 캡처: `phone/B01_홈-기본.png`, `B03_더보기-시트.png`, `J02_홈-경기날.png`, `N01_시즌종료-위.png`, `pc/B01_홈-기본.png`
- 컴포넌트: 새 컴포넌트 **Dock** 필요(Icon·배지 재사용). 더보기는 BottomSheet + OptionRow로 됨.

**A2. 자동 진행 시트** (C.44)
- 목적: [자동 진행]을 누르면 어디까지 진행할지 고른다.
- 데이터: 시작 날짜, 경기 수 빠른 선택(1·3·5·10·시즌 끝(n)) + 직접 입력, [n경기 자동 진행], "다음 중요 경기 직전까지" 목록(더비 매치·국가대표 A매치·국가대표 토너먼트·챔피언스리그·컵: 날짜·상대·남은 경기 수, 없으면 "아직 없음").
- 상태: 더비 있음/없음, 비시즌(경기 없음).
- 캡처: `phone/M01_자동진행-시트.png`
- 컴포넌트: BottomSheet + Tabs(세그먼트) + OptionRow로 됨.

**A3. 자동 진행 레이어 + 끝 요약** (C.44)
- 목적: 진행 중에는 화면 위에 흐린 레이어와 진행 카드, 끝나면 요약 토스트.
- 데이터: "자동 경기 진행 중", n/m경기, 날짜·순위·라운드, 진행 막대, [중단](누르면 "멈추는 중"). 끝 요약 "3경기 2승 0무 1패 · 내 골 0 도움 0 · 4위(4.3조)".
- 상태: 진행 중 / 멈추는 중 / 끝(토스트) / 이적 제안 등으로 중간 멈춤.
- 캡처: `phone/M02_자동진행-레이어.png`, `M03_자동진행-끝요약.png`
- 컴포넌트: Modal 변형 + Meter + Toast. 레이어 스타일은 새로.

**A4. 새 기능 안내 모달** (C.38·C.39)
- 목적: 전술·성장(포인트 찍기) 등이 처음 열릴 때 한 번 안내.
- 데이터: 아이콘, 제목 "새 기능 · 전술", 설명 2~3줄, [확인].
- 캡처: `phone/M03_자동진행-끝요약.png`(전술), `M04_새기능-전술-안내.png`(성장)
- 컴포넌트: Modal로 됨(아이콘 머리 변형).

**A5. 설정 화면** (C.43·C.44·C.44a, 새 화면)
- 목적: 게임 설정을 한곳에. 홈 오른쪽 위 ⚙, 타이틀 [설정 · 페이스온], 독 더보기에서 들어온다.
- 데이터(섹션 순서): ① 경기 진행 — 내 선수 결정 직접/자동, 정지 빈도 3단, 다른 경기 계산 전체 엔진/빠른 진행, 난이도(표시만) ② 경기 화면 보기 — 선수 표시 등번호/얼굴/캐릭터, 방향 자동/항상 가로/항상 세로, 선수 크기 보통/크게/아주 크게, 이름 표시 켬/내 선수만/끔 ③ 선수 이름(A7) ④ 경고 누적 등 기록 ⑤ 저장과 안내(세이브 관리 링크, 첫 플레이 안내 다시 보기) ⑥ 페이스온(A6) ⑦ 페이스팩 zip 내보내기/가져오기 ⑧ 버전 줄.
- 상태: 경기 중(일부 잠금), 기기 저장 표시("이 브라우저에 저장").
- 캡처: `phone/C01_설정-위.png`, `C02_설정-전체.png`, `pc/C02_설정-전체.png`
- 컴포넌트: SectionTitle + OptionRow + Tabs(세그먼트) + Switch로 됨. **긴 화면이라 섹션 접기 또는 상단 섹션 탭이 필요**(문제 6).

**A6. 페이스온 편집** (C.43)
- 목적: 선수·구단 이미지를 사용자가 올린다.
- 데이터: [선수|구단] 탭, 검색, 목록(얼굴·이름·팀·포지션), 고른 선수의 **나이대 칸 3개**(~23세/24~29세 지금 나이/30세~, 각 [올리기]/[지우기]), 정사각형 미리보기(투명 = 체크무늬) + 확대·위아래·좌우 슬라이더 + [저장][취소].
- 상태: 이미지 없음(기본 아바타), 올린 뒤, 사진 없는 선수, 구단 탭(엠블럼).
- 캡처: `phone/C03_설정-페이스온-편집.png`, 참고 `docs/design/c43-check/8_위치맞추기-정사각형미리보기.png`
- 컴포넌트: Avatar·Crest·Slider·Tabs로 됨. 미리보기 프레임은 새로.

**A7. 선수 이름 편집** (C.44a)
- 목적: 아무 선수의 별명·짧은 이름을 고친다(경기 화면 라벨 = 별명 > 짧은 이름).
- 데이터: 검색 + 팀 거르기(모든 팀/각 팀/리그 밖), 결과 목록(이름·팀·지금 라벨), 고른 선수의 풀네임·경기 화면 라벨·별명 입력·짧은 이름 입력·[저장][되돌리기]. 내 선수는 선수 화면 "이름" 칸에도 같은 편집.
- 캡처: `phone/C04_설정-선수이름-편집.png`, 참고 `docs/design/c44a-check/phone_1_선수화면-별명.png`

**A8. 경기 화면 보기 시트** (C.43·C.44a)

- 캡처: `phone/K06_결정결과-재생중.png`, `K07_결정결과-결과띠.png`, 참고 `docs/design/c36-check/7_카드결과띠-*.png`

**A11. 카드 획득 3택 1** (C.36·C.39)

**A12. 이적 제안 화면** (C.42)
