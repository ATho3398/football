# C.79c 시도 기록 — R1 직선 수신 능력치 (미달, main 배포 안 함)

브랜치 `claude/c79c-aerial` (origin/main 54c4be8 + engine-manager-14 823ec22). 코드의 새 스위치는 모두 기본 0이라 엔진 56과 같다(배포 안 함).

## 넣은 것 (스위치, `config.ts prob`)
- `recvTouch`·`recvW`·`recvScale` — `duel.ts longRecvScore/longRecvWin`: 크로스가 아닌 공중볼 착지 경합에서 차 보낸 팀 선수 점수 = 볼 컨트롤 0.4 + 점프 0.3 + 근력 0.3(+키). 판단(candidates 롱패스 `aerial`)·실행(resolveFlight 롱볼 수신, resolveAerial)이 같은 식.
- `landSkill` — `landingShare`: 양 팀 첫 도착 선수의 같은 점수 차 / recvScale 를 로짓에 더함(판단 = resolveAerial 실행 점수).
- `touchSkill`·`touchCenter` — `duel.ts longTouchApply`: 공중 패스(airPass 초과) pFlight 실패 몫 × exp(−touchSkill × (받는 능력 − center)/10). candidates 의 pFlight 를 makePass 가 그대로 쓰므로 판단 = 실행.
- `c78s-fit.ts`: `경로=값` 덮어쓰기, `STATS=1` 세트별 롱패스·성공·슛·공중.
