# 역할 확장과 엔진 층 구조 초안 (기획 세션 작업 중)

코드 세션이 E3.5~E3.6을 진행하는 동안 `game-design.md`를 고치지 않기 위해 여기에 모은다. 코드 세션이 쉬면 부록 E.6(역할 표), E.5(포메이션), E.19(전술), E.17(덩어리), 18.1, 부록 F(시그니처 카드)에 합친다.

## 확정 (2026-10-15)
1. **역할 31개**(포지션별 플레이 스타일). 사용자 필수: 윙의 윙포워드, 크랙형 윙어, 정통 윙어, 라움도이터.

   | 포지션 | 역할 |
   |---|---|
   | 윙(LW/RW/LM/RM) | 정통 윙어, 윙포워드(기존 인사이드 포워드 흡수), 크랙형 윙어, 라움도이터, 와이드 미드필더 |
   | ST/CF | 포처, 타겟맨, 펄스 나인, 침투형 스트라이커 |
   | CAM | 클래식 10번, 섀도 스트라이커, 프리롤, 박스 침투형, 엔간체 |
   | CM | 박스투박스, 딥라잉 플레이메이커, 메짤라(기존 공격형 8번 흡수), 캐리어, 홀딩 CM |
   | CDM | 앵커, 볼 위너, 레지스타(피를로형: 수비 가담 거의 없이 조율, 기존 CDM 딥라잉 플레이메이커 흡수), 하프백 |
   | 풀백 | 공격적 풀백, 수비형 풀백, 인버티드 풀백, 컴플리트 윙백 |
   | CB | 스토퍼, 볼 플레잉 CB, 커버 CB, 리베로 |

   보류: 와이드 플레이메이커, 프레싱 포워드.
2. **포메이션 3종 추가**(5 → 8종): 4-3-1-2(다이아몬드), 4-1-4-1, 3-4-3.
3. **공용 움직임 모듈 4개**. 특수 역할은 이 모듈을 조합한다.
   - ① 빈 공간 찾기: 라움도이터, 프리롤, 섀도 스트라이커
   - ② 줄 사이 이동: 펄스 나인, 하프백, 리베로, 인버티드 풀백
   - ③ 공 요구·소유 성향: 크랙형 윙어, 엔간체, 레지스타
   - ④ 수비 의무 면제와 커버 재배분: 레지스타, 크랙형 윙어, 엔간체
4. **역할 반응 점검**:
   - 역할을 바꾸면 활동 위치(히트맵), 터치, 침투, 태클 지표가 역할 설명대로 바뀌어야 한다.
   - 같은 포지션 안에서 어떤 역할도 일방적으로 강하지 않아야 한다(득실 영향 ±0.1골 이내).
5. **일정**: E3.5 → E3.6(전술 화면) → **E3.7(역할 확장 + 포메이션 3종 + 움직임 모듈 4개)** → 사람 확인 → E4.
6. 역할 시그니처 카드는 역할 수만큼 31장이 된다(카드 전체 약 73장). 시그니처 목록은 역할 값과 함께 다음에 적는다.

## 엔진 층 구조 (모든 요소가 들어가는 방식)
사용자 질문: "움직임으로 고려할 게 스탯, 전술, 포지션, 엔진 평균값 등등 많은데 엔진에 다 담을 수 있나?" → 담을 수 있다. 요소마다 **맡는 단계가 다르고**, 서로 덮어쓰지 않게 층으로 쌓는다.

| 층 | 무엇을 정하나 | 들어가는 곳 |
|---|---|---|
| 1. 포메이션·포지션(슬롯) | 기본 자리 | 목표 위치의 출발점 |
| 2. 팀 전술(성향, 라인, 압박, 빌드업, 폭) | 팀 전체가 어떻게 움직이고 무엇을 선호하나 | 대형 이동(라인 x, 폭, 압박 거리), 판단 가중(× 0.7~1.3) |
| 3. 역할(31개, 움직임 모듈) | 그 자리에서 이 선수가 어떻게 움직이나 | 슬롯 대비 오프셋, 침투·내려오기·압박 빈도, 판단 선호 가중 |
| 4. 성향 슬라이더(내 선수만) | 같은 역할 안에서의 개인 버릇 | 역할 가중에 ±20% |
| 5. 상황(스코어, 시간, 체력, 수적 차이, 홈) | 지금 상황에서의 조정 | 긴장도 가중, 라인/압박 보정, 스태미나 |
| 6. 능력치 | **실제로 얼마나 잘 해내나** | 이동 속도·가속, 위치 오차, 판단 일관성(τ), 모든 성공 확률 |
| 7. 카드(내 선수, 결정 순간만) | 특별한 선택지, 소폭 보너스 | 선택지 추가, 확률 합계 상한 +15%p |
| 8. 엔진 공용 상수("평균값") | 단위와 규모만 맞춘다 | 모든 선수 공통. 리그 평균 통계가 실제와 맞게 하는 눈금이지, 누구의 행동을 정하는 값이 아니다(E.15.1) |

- **계산 순서**:
  - 목표 위치 = 슬롯(1) + 전술 대형 이동(2) + 역할 오프셋·모듈(3) + 상황(5)
  - 실제로 그 자리에 가는지는 능력치(6)가 정한다(속도, 체력, 위치선정 오차).
  - 판단 효용 = 공용 가치(골 = 1, 8) × 전술 가중(2) × 역할 가중(3) × 성향(4) × 상황(5)
  - 얼마나 일관되게 좋은 선택을 하느냐는 판단 능력치(6)가 정한다.
  - 결과 = 능력치 판정(6) + 카드(7, 상한 있음)
- **덮어쓰기 금지 규칙**:
  - 2~5층은 "어디로 가고 무엇을 선호하나"만 바꾸고 성공 확률을 직접 바꾸지 않는다.
  - 성공 확률은 6층(능력치)과 7층(카드, 내 선수만)만 바꾼다.
  - 8층은 모두에게 같다.
- **가중의 크기**: 층마다 곱하는 가중은 대체로 0.7~1.4다. 여러 층이 겹쳐도 한쪽으로 폭주하지 않게 효용 가중 곱의 전체 범위를 0.5~2.0으로 자른다.
- **검증**: 층마다 반응 점검을 둔다(스탯 반응 E.15.1, 전술 반응 E.15, 역할 반응 위 4번). 모든 조합을 다 시험할 수는 없으므로 무작위 조합 표본(`balance:sweep`)과 "만능 조합 없음" 점검으로 확인한다.
- **성능**: 22명 × 초당 10번 계산이고 층이 늘어도 곱셈 몇 번과 모듈 판정이 추가될 뿐이다. 지금 경기당 약 0.7초에서 E3.7 이후 1초 안팎을 예상한다(목표 2초 이내).
