# Claude Design 수정 요청 2차 (2026-10-15)

1차 수정 요청(`docs/design-change-request.md`, 전술 화면 등)에 이어지는 변경분이다. 기존 토큰과 컴포넌트 스타일은 유지하고, 이미 만든 화면은 해당 부분만 고치고, 새 화면은 같은 스타일로 만든다. 모바일 390 × 844 세로 기준, 다크/라이트 공용 토큰, 한국어 UI. 화면 명세 본문은 `docs/ui-spec-for-design.md`의 I.17, I.18이다.

## 1. 결정 순간 패널 (I.5 개정, 가장 중요)
- 구조: 위에서부터 **선택지 3개(안전/균형/도박) → 패 카드 줄 → [맡기기] [확정]** 버튼.
- **확률 카드**를 탭하면 선택지의 확률이 바로 바뀌어 보인다. 바뀐 부분은 따로 표기한다. 예: "슛 26% (+8 카드)", 오른 값은 초록, 내린 값은 빨강.
- **플레이 카드**(예: 라보나 크로스, 칩슛)를 탭하면 **4번째 선택지가 카드 색 테두리로 추가**된다. 카드를 다시 탭하면 취소된다.
- 선택지를 누르면 코트에 화살표 미리보기가 나오고, [확정]으로 실행한다.
- **[맡기기]**: 이번 순간을 엔진에 넘긴다. 카드는 쓰지 않고 패에 남는다. 눈에 잘 띄지만 [확정]보다는 약한 위계로 둔다.
- artboard:
  - 결정패널-기본
  - 결정패널-확률카드적용
  - 결정패널-플레이카드(4번째 선택지)
  - 결정패널-선택미리보기(코트 화살표)

## 2. 경기 화면 (I.4 개정)
- 상단 속도 컨트롤 옆에 **직접/자동 토글**을 둔다. 경기 중 언제든 바꿀 수 있다.
- **재개 대기 구간**(스로인 준비 등)은 자동으로 약 4배속으로 빨리 감긴다. 이때 상단에 "빨리 감기 중" 작은 표시를 띄운다.
- 결정 순간에는 0.5초 슬로모션 뒤에 정지하고, 패널이 올라온다(전환 연출 스케치 1장).
- 설정 시트: **정지 빈도 3단계**(모든 결정 순간 / 중요한 순간만(기본) / 결정적 순간만), 빨리 감기 켜기/끄기.

## 3. 전술 화면 (I.16 개정)
- **전술 세트 3개** 탭(예: 기본 / 강팀 상대 / 약팀 상대)과 각 세트에 짝지은 덱 이름.
- **포메이션 8종**: 기존 5종 + 4-3-1-2, 4-1-4-1, 3-4-3.
- **커스텀 포메이션 편집**: 미니 피치에서 선수를 끌어다 놓으면 보이지 않는 격자(가로 5레인 × 세로 6줄)에 붙고 포지션 라벨(예: CAM, LW)이 뜬다. 규칙 위반 칸은 붉게 표시하고 이유를 한 줄로 보여 준다(예: "수비 줄은 3명 이상"). artboard: 전술-커스텀편집(끄는 중), 전술-배치불가.
- **역할 선택 바텀시트**: 역할이 포지션별 4~5개(총 31개)로 늘었다. 역할마다 이름, 한 줄 설명, 그 선수의 적합도, 시그니처 카드 이름을 보여 준다. 예시 윙 역할: 정통 윙어, 윙포워드, 크랙형 윙어, 라움도이터, 와이드 미드필더.
- **상대 정보 블록**: 상대 성향·포메이션, 최근 5경기, 능력치 비교 힌트 2~3줄(예: "상대 공격진이 빠름 → 높은 라인이면 뒷공간 위험").

## 4. 덱 편집 (I.9 개정)
- **덱 세트 3개**를 저장하고, 전술 세트와 짝지을 수 있다.
- 역할이 맞지 않아 쓸 수 없는 **시그니처 카드는 회색**으로 표시하고 교체 제안 버튼을 둔다.
- **카드 종류 표기**: 플레이 / 세트피스 / 패시브 / 콤보 / 관리 / 시그니처 / **지시**(5단계에서 활성). 플레이 카드는 "새 선택지"임을 아이콘으로 구분한다.
- **포지션군 태그**: 공용 / 공격 / 미드 / 수비. 예전의 "수비" 카드 종류는 이 태그로 옮겼다(수비 플레이 카드 = 종류 "플레이" + 태그 "수비"). 디자인 시스템의 수비 색·아이콘은 태그용으로 쓴다.
- **지시 카드(지시 이행 / 독단 / 감독의 신뢰)는 유지한다.** 이미 만든 카드-지시이행·독단 화면은 지우지 말고 문구만 바꾼다: 지시 이행 = "내가 정한 역할대로 팀플레이(팀 결과·신뢰도 +)", 독단 = "역할을 벗어난 개인 플레이(성공 시 평점·XP 보너스, 실패 시 신뢰도 −)". 감독이 지시하는 게 아니라 사용자가 전술 화면에서 정한 역할이 기준이다.
- 경기 전 화면에 "이 덱에 못 쓰는 카드 n장" 경고.

## 5. 경기 후 (I.6 개정)
- **내 결정 기록** 목록: 분, 장면, 고른 선택지(또는 "맡김"/"자동" 배지), 확률, 결과, 평점 변화. 항목을 탭하면 그 장면의 **피치 리플레이**(작은 코트 + 재생 바)를 연다. 전술 리포트 옆 탭으로 둔다.

## 6. 새 화면 (I.18)
- **캘린더(홈 상단)**:
  - 오늘 날짜, 다음 일정, [계속] / [하루 진행]
  - 다른 경기를 계산하는 동안 진행 표시("오늘 경기 3/5 계산 중")와 [중단]
  - 이적시장 기간 배지(여름/1월)
- **훈련 계획**:
  - 주간 템플릿(요일별 7종 중 선택: 기술(묶음 선택), 고강도, 포지션·역할, 세트피스·카드, 영상 분석, 회복, 휴식)
  - 날짜를 누르면 그날만 바꾸는 시트
  - 묶음별 훈련 게이지(30칸)
  - 오늘 훈련의 XP·피로 변화 미리보기(수치는 작다: XP 0~1.5, 피로 −2~−6), 주간 XP 상한 6 표시
- **휴가**: "A매치 휴식기, 9월 17일까지 휴가" 안내 카드와 [휴가 끝까지 넘기기]. 리그 외 경기가 있으면 그 일정에서 멈춘다는 안내.
- **주전 경쟁 카드(홈)**:
  - 신뢰도 게이지
  - 나와 경쟁자 2~3명의 선발 점수 막대(슬롯 OVR / 신뢰도 / 폼 / 피로로 분해)
  - 최근 신뢰도 변화 이유 5개(예: "+2 평점 7.4")
  - 다음 면담 조건
- **세이브**: 수동 슬롯 3개, 자동 저장 시각, 파일 내보내기/가져오기.

## 7. 샘플 데이터 추가
- 결정 순간 예(85분 0-0, 박스 앞): 안전 = 옆 패스 78%, 균형 = 직접 슛 26% (+8 카드), 도박 = 침투 패스 38%, **플레이 카드 "감아차기"** = 먼 포스트 감아차기 21%.
- 훈련 주간 예: 월 회복 / 화 기술(마무리) / 수 기술(마무리) / 목 휴식 / 금 영상 분석 / 토 경기 / 일 회복.
- 주전 경쟁 예: 김민준 선발 점수 62.4(슬롯 OVR 60 + 신뢰도 +0.6 + 폼 +1.8) vs 경쟁자 64.1 → 선발 확률 24%.

## 8. 진행 순서
1. 결정 순간 패널(1)과 경기 화면(2)
2. 전술 화면(3)과 덱 편집(4)
3. 경기 후(5)
4. 새 화면(6)

각 artboard 이름은 "화면-상태" 형식으로 붙인다.
