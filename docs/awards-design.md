# 개인 시상 설계 (pending 140, 2026-10-20 21:38 KST 마스터 V, 사용자 "평점순은 단순하고 재미없다")

## 1. 원칙
- **평점 1등 = 수상이 아니다.** 실제처럼 *누가 뽑느냐*(투표단)마다 보는 것이 다르고, 결과는 투표로 정해진다. 같은 시즌이라도 상마다 수상자가 갈릴 수 있다.
- **서사가 점수다.** 트로피, 큰 경기 결정적 순간, 기록 경신, 화제성이 숫자만큼 중요하다(기자단).
- **시즌 내내 레이스가 보인다.** 매달 "발롱도르 파워 랭킹" 기사·홈 칩으로 내 순위와 앞선 선수, 남은 기회(챔스 결승, 월드컵)를 보여 준다. 시상식은 후보 발표 → 최종 3인 → 발표(득표수 공개) 순 이벤트.
- 결정성: 투표 난수는 월드 시드 + 시즌 + 상 id 로 고정.
- 수치는 모두 `balance.ts` `awards` 절.

## 2. 선수 시즌 이력서 (모든 상이 공유)
시즌 동안 선수별로 쌓는다(내 선수 + 고른 리그 NPC, 엔진 기록. 빠른 진행 경기는 그 기록).
- **실적**: 골·도움(포지션 환산), 평균 평점, 출전·분, MOM, 수비 지표(클린시트·태클·가로채기), GK(선방률·클린시트·PK 선방).
- **트로피**: 리그·국내 컵·챔스·대표팀 대회(월드컵·대륙컵) 우승/결승/4강, 팀 안 비중(그 대회 출전·공격포인트).
- **결정적 순간(클러치)**: 결승골, 80분 뒤 동점·역전골, 결승전·준결승·챔스 녹아웃·더비·상위 6팀 상대 골/MOM, 해트트릭. 경기 무게 × 순간 무게로 점수.
- **서사**: 시즌 기록 경신(리그 최다골 등), 첫 풀시즌 폭발, 부상 복귀, 약팀 돌풍(팀 예상 순위 대비 성적), 이적 첫 시즌, 나이(10대·35세+). 기자단만 크게 본다.
- **인기**: 위상 티어 + 시즌 화제(기사 수, 팬 이벤트) — 팬 투표만 본다.

## 3. 투표단 (상마다 섞는 비율이 다름)
| 투표단 | 보는 것 | 성향 |
|---|---|---|
| 기자단 | 트로피·클러치·서사 많이, 실적 보통 | 큰 무대 편향, 같은 사람 연속 수상에 약한 피로(새 얼굴 선호) |
| 선수단(동료) | 실적·꾸준함(평점 분산 낮음)·포지션 영향, 트로피 적게 | 수비수·미드도 잘 뽑음 |
| 감독·주장 | 실적·트로피 반반, 대표팀 활약 | 같은 리그/국적 약간 편향 |
| 팬 | 인기·골·하이라이트(해트트릭·극장골) | 공격수 편향 |
- 투표자 N명(예 기자 100), 각자 위 가중치 + 개인 노이즈로 상위 3명(또는 5명)을 뽑아 점수(5·3·1 / 6·4·3·2·1). 합계가 결과, 득표·1위표 수 공개.
- 후보 자격·명단(30인 등)은 이력서 종합 점수 상위.
