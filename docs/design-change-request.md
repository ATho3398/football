# Claude Design 수정 요청 (2026-10-15)

`docs/ui-spec-for-design.md`(디자인 요청서)를 이미 받아 작업 중인 디자인에 대한 변경분이다. 요청서 본문도 같은 내용으로 갱신했다. 이미 만든 산출물은 아래 항목만 고치면 된다.

## 0. 가장 큰 변경: 팀 전술은 사용자가 정한다
- 게임은 여전히 **선수 한 명 시점**이지만, **팀 전술만큼은 사용자가 감독처럼 직접 정한다.** 선발 여부와 교체는 감독 NPC가 정한다(감독 신뢰도).
- 전술은 세 층이다.
  1. **전술 성향 6종**: 균형, 티키타카, 게겐프레싱, 역습, 직선(롱볼), 수비 블록
  2. **포메이션**: 5종(4-4-2, 4-3-3, 4-2-3-1, 3-5-2, 5-3-2)에서 큰 틀을 고르고, **내가 뛸 위치(슬롯)**를 정하고, **11개 슬롯마다 역할**을 정한다(예: CB 볼 플레잉 / 스토퍼 / 커버)
  3. **세부 전술 4개**: 수비 라인, 압박, 빌드업(짧게/혼합/직선), 공격 폭(좁게/보통/넓게). 각각 3단계
- 성향을 고르면 세부 전술과 역할의 기본값이 채워지고, 사용자가 그 위에서 바꾼다. 효과는 미세하다(능력치가 결과를 정하고, 전술은 움직임 방식을 바꾼다).

## 1. 새 화면: 전술 화면 (I.16)
- 진입: 경기 탭, 또는 홈 "다음 경기" 카드의 "전술" 버튼.
- 구성(위에서 아래):
  ① 전술 성향 6종 칩 + 적합도 배지(잘 맞음 / 보통 / 안 맞음, 팀 능력치 기준 힌트)
  ② 포메이션 선택(5종) + **미니 피치**: 11개 슬롯에 선수 이름과 역할. 슬롯을 탭하면 역할 선택 바텀시트(역할 3개, 각 역할 설명 한 줄과 그 선수의 적합도). 내 슬롯은 강조 링. "내 위치로 지정" 버튼과 **슬롯별 내 OVR**(주 포지션이 아니면 낮아짐)
  ③ 세부 전술 4개, 각각 3단계 세그먼트 컨트롤
  ④ 저장 / 기본값 되돌리기
- 상태(artboard):
  - `전술-기본`
  - `전술-역할선택`(바텀시트)
  - `전술-성향변경확인`("세부 전술과 역할을 성향 기본값으로 바꿀까요?")
  - `전술-주포지션밖경고`(내 위치를 다른 포지션 슬롯으로 옮길 때 OVR 손해 표시)
  - `경기화면-하프타임전술`(경기 중 변경 바텀시트: 포메이션, 세부 전술, 역할만)
- 전술 성향 6종에 쓸 아이콘이나 엠블럼을 만들어 달라(칩, 팀 정보 표시에 공용).

## 2. 홈 (I.3)
- "다음 경기" 카드에 다음 세 가지를 추가한다.
  - **내 팀 전술 요약**: 성향, 포메이션, 내 위치·역할. 예: "역습 · 4-2-3-1 · ST 골잡이"
  - **"전술" 버튼**
  - **상대 팀 전술**: 예: "리버풀 · 게겐프레싱 · 4-3-3"
- 새 상태 `홈-출장정지`: 레드카드나 옐로 5장 누적으로 다음 경기에 못 나온다. 배너("출장 정지 1경기")를 띄우고 경기 버튼은 "결장(관전)"으로 바꾼다.

## 3. 경기 화면 (I.4)
- **경기 중단(재개 대기) 상태 추가**: 실제 축구처럼 경기의 약 1/3은 공이 죽어 있다(스로인, 골킥, 프리킥 준비, 골 세리머니, 교체). 이때 마커는 걸어서 자리를 잡는다. 정적 프레임 `경기화면-재개대기`(예: 스로인 준비, 상단에 작은 상태 라벨)를 추가해 달라.
- **이벤트 아이콘 추가**: 스로인, 골킥, 상대 전술 변경(예: "상대가 라인을 올립니다"). 스로인과 골킥은 경기당 수십 번 나오므로 **피드에서는 기본으로 숨기거나 약하게** 표시하고, 코트 위 작은 표시로만 보여 준다.
- 스코어 바 또는 그 아래에 **양 팀 포메이션과 성향 칩**(작게)을 넣는다.
- 내 선수 상태 줄에 **내 슬롯·역할 칩**을 넣는다.
- 하프타임과 경기 중단 때 **"전술" 버튼** → 위 `경기화면-하프타임전술` 바텀시트.

## 4. 결정 순간 선택 패널 (I.5)
- 선택지 예시에 새 플레이를 반영해 달라(샘플 문구용): **컷백 패스**(측면 깊은 곳에서 뒤로), **버티기**(등지고 공 지키기), **레이오프**(2선에게 내주기), 중거리 슛. 레이아웃 변경은 없다.

## 5. 경기 후 (I.6)
- **전술 리포트** 작은 블록을 추가한다: 점유율, 슈팅, 상대 진영에서 공을 뺏은 횟수, 롱패스 비율. 내 전술이 어떻게 작동했는지 보는 용도다. 우선순위는 하이라이트 다음이다.

## 6. 선수 상세 (I.8)
- "역할과 성향 설정(18.1)"을 **"성향 설정"(슬라이더 3개: 이기심, 돌파, 수비 가담)**으로 바꾼다. 역할은 전술 화면에서 슬롯 역할로 정한다. 선수 상세에는 현재 역할을 읽기 전용으로 보여 주고, 전술 화면으로 가는 링크를 둔다.
- **경고 누적(옐로 n/5)**과 출장 정지 표시를 추가한다.

## 7. 카드 (I.9)와 면담 (I.11)
- **지시 카드**의 의미가 바뀌었다. "감독 지시"가 아니라 **"내가 정한 역할대로 팀플레이(지시 이행)"** 대 **"역할을 벗어난 개인 플레이(독단)"**다. 카드 문구와 아이콘을 이 의미로 맞춰 달라.
- 면담: 신뢰도가 높을 때 보상 면담 선택지에 **"선호 슬롯 보장"**(내가 고른 위치에서 선발 보장)을 추가한다.

## 8. 샘플 데이터 추가
- 내 팀 "리버사이드 FC": 역습, 4-2-3-1, 라인 낮음 / 압박 보통 / 빌드업 직선 / 폭 보통. 김민준은 ST 슬롯, 역할 골잡이. 적합도 "보통".
- 다음 상대 리버풀: 게겐프레싱, 4-3-3.
- 경기 피드 예 추가: `46' 하프타임 전술 변경: 라인 보통으로` / `71' 상대가 라인을 올립니다` / `63' 김민준, 버티기 성공 → 레이오프`.

## 9. 우선순위
- 기존 순서는 그대로다(토큰/컴포넌트 → 경기 화면·선택 패널·덱 편집 → 홈·**전술 화면**·경기 후·포인트·선수 상세 → 나머지).
- 이미 만든 경기 화면과 홈에는 2, 3번 변경만 덧붙이면 된다.
