# 엔진관리자26 진단 — 크로스 순간 박스 인원 · 리바운드 골 (2026-11-04)

근거: 골 분포 패치(부록 C.80u)에서 크로스 순간 박스 인원 2.5명(목표 3~4)과 리바운드 골 3%(목표 5~10)가 수치 레버로 안 움직였다.
측정: `scripts/diag/em26-box-rebound.ts`(엔진 상태 읽기만), 표준 경기 4-2-3-1 균형 75:75, 홈·원정 짝, **변형마다 300경기**(시드 41000·42000·43000·44000 × 75).
실험 스위치 4개를 엔진에 넣었고 **모두 기본 0(끔)** — 기본값에서는 동작이 바뀌지 않는다(`npm test` 통과).

## 3. 처방

### 박스 인원 (수치 레버, 바로 적용 가능)
1. `offball.edgeZone` 22 → **12** (두 번째 미드 자리를 박스 안 페널티 지점 바깥쪽으로) — +0.14
2. `offball.lateRunFromX` 0.68 → **0.6** (최종 역할 자리 출발을 8 m 일찍 — 먼 쪽 윙어·두 번째 미드가 덜 늦음) — +0.10
3. 판단 보정 `decide.bias.crossBox` 0 → **0.06**, `crossBoxMin` 3 (박스 동료가 3명 미만이면 모자란 1명당 크로스 효용 −0.06 — 기다렸다 올리기. 실행 불변, 판단에 보이는 특징만) — 이 스위치는 이 브랜치에 기본 0으로 들어 있음(`src/engine/onball.ts` 크로스 후보, `config.ts decide.bias`)
- 셋 합: **2.47 → 2.90**(착지 3.16, 4명 이상 6% → 17%). 목표 하한 3.0 에 0.1 모자람. 
- 예상 영향: 득점 **+0.2/경기(3.24 → 3.45, +6%)** → 총량은 `keeper.saveBase` 소폭(+0.02~0.03)으로 되돌림. 크로스 수 −12%, 미드 골 비중 소폭 ↑(CDM 박스 도착), 이동 거리: CDM 이 더 달려 1인 최다 km 소폭 ↑(미측정 — 적용 패치에서 em25-dist 로 확인). 상성: 크로스를 많이 쓰는 성향(직선·와이드)에 유리할 수 있어 960 두 벌 확인 필요(이번엔 미측정).
- 3.0 을 넘기려면 구조(최소 범위): 4-2-3-1 처럼 2선이 CDM 뿐이면 두 번째 미드가 너무 깊다 → `finalThirdJob` 의 edge 담당을 "공에 가장 가까운 CM/CAM/CDM" 대신 "edge 자리에 가장 빨리 닿는 선수(풀백 포함)"로. 또는 목표 자체를 **착지 순간 인원**(지금 2.77 → 처방 뒤 3.16)으로 재정의 — 실축 "크로스 때 박스 인원" 자료도 대부분 공이 들어갈 때 기준.

### 리바운드 (수치로 안 됨 — 구조 또는 목표 재정의)
- 수치 레버(`catchBase` 0.05 · `parryCorner` 0.2 · `parrySpeed` · `parrySpread` · `handBlock`)는 쳐낸 공의 **수**만 늘리고(602 → 1050) 공격 첫 접촉·슛 질은 그대로 → 골 비중 3% 근처. 처방하지 않음(쳐냄 비율 50%는 실축 범위 밖).
- 병목은 슛 순간 골 앞(6 m 안) 공격 인원. 박스 인원 처방이 들어가도 6 m 안 0.8 → 0.87 뿐.
- **추천 A (구조, 최소 범위)**: 우리 팀 슛 **직전**(소유자가 골 20 m 안·슛 후보 효용 최상) 박스 안 2선 1명이 골 앞 6~8 m 중앙("골문 앞 쇄도")으로 — 실험 스위치 `offball.shotFollow` 를 "슛 뒤"가 아니라 "소유자가 슛 거리에 들어오면"으로 앞당긴 판. 예상: 쳐낸 공 공격 첫 접촉 27% → 40%, 리바운드 슛 xG ↑ → 리바운드 골 3 → 5% 근처(미검증). 수비 쪽도 같은 규칙(골 앞 커버)이 붙으면 상쇄될 수 있어 공격만.
- **추천 B (기획)**: 목표를 3~6%로 낮춤 — 엔진의 수비가 크로스 순간 골에서 7.7 m 까지 내려앉는 구조라 골 앞 인원 차가 실축보다 크다. 수비 줄 높이를 바꾸는 건 다른 지표가 다 흔들리는 큰 변경.

## 4. 넣은 실험 스위치 (모두 기본 0, 이 브랜치 `claude/em26-box-rebound`)
| 상수 | 위치 | 뜻 |
|---|---|---|
| `decide.bias.crossBox` / `crossBoxMin` 3 | onball 크로스 후보 | 박스 동료 부족 1명당 크로스 효용 감점 |
