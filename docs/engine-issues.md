1. **높은 라인 뒷공간이 처벌되지 않는다**: 라인 높음 + CB 속도 −10 이 실점을 줄인다(1.44 → 1.05). 침투 패스 수신은 +52%인데 골로 안 이어진다 → 달리기 경쟁·GK 스위퍼(C.28 블록 뒤 공간 = GK 몫)가 너무 잘 막는지.
2. **낮은 라인·블록이 박스 앞 밀집을 만들지 못한다**: 블록 슈팅 허용 +20%, 실점 +25%. `blockLineMax` 16.5 m·`blockGap` 12 m가 줄을 뒤로만 빼고 공 쪽 좁히기·슛 블록 위치가 없다(C.29 fix 의 밀집 가설과 같은 축).
3. **압박 비용이 없다**: 압박 높음 이동 거리 −1.9%(목표 +3), 스태미나 배수 0.95+0.15p 의 차이가 4%뿐. 높은 압박의 대가(체력·뒷공간)가 결과에 안 나온다.
