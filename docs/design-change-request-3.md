# Claude Design 요청 3차: 카드 세트 (2026-10-15)

카드 76장(일반 카드 42장, 역할 시그니처 31장, 지시 3장)의 **카드 앞면과 그림**을 미리 만들어 두기 위한 요청서다. 카드 틀(`GameCard` 컴포넌트, full·deck·mini·hand 4가지 크기, 사선 분할, 희귀도 색)은 이미 `docs/design/player-one-design/`에 있다. 이번 작업은 **그 틀에 들어갈 내용**, 곧 카드별 그림(`card.art`), 효과 문장, 조건 문구를 채우는 것이다. 틀의 규칙(`design-system/README.md`의 "게임 카드", `components/GameCard/README.md`)은 그대로 지킨다.

- 기준: 기획서 16번, 부록 F(F.0, F.2, F.4), 부록 E.6 역할 표. 기획서와 다르면 기획서가 우선이다.
- **수치는 초안이다.** 경기 엔진의 내 선수 개입 단계(E4)를 만든 뒤 다시 맞춘다. 카드 이름, 종류, 희귀도, 장면은 확정이고 %p 같은 숫자는 바뀔 수 있다. 그래서 숫자는 효과 문장의 `hi` 칸에만 넣고, 그림에는 숫자를 넣지 않는다.

## 1. 카드 규칙 요약 (화면 문구에 필요한 것만)

### 종류 7가지 (`type`)
| 종류 | 하는 일 | 경기에서 |
|---|---|---|
| 플레이 `play` | 결정 순간에 **4번째 선택지**를 연다(예: 라보나 크로스, 칩슛). 카드의 핵심 | 쓰면 그 경기에서 소모 |
| 세트피스 `setpiece` | 프리킥·PK·코너 전용. 새 선택지를 여는 것과 확률만 올리는 것이 섞여 있다 | 덱에 3장까지 |
| 패시브 `passive` | 쓰면 남은 경기 동안 효과가 유지된다 | 동시에 2장까지 장착 |
| 콤보 `combo` | 직전 플레이가 성공하면 다음 장면에 보너스 | 1회 |
| 관리 `manage` | 이번 턴 보조(확률 조금, 실패 완화, 패 교체) | 1회 |
| 시그니처 `signature` | 역할마다 1장. **그 역할을 맡았을 때만** 쓸 수 있다. 모두 희귀 | 역할이 다르면 회색과 [교체 제안] |
| 지시 `order` | 내가 정한 슬롯 역할을 따를지 말지(이행/독단). **5단계에서 활성** | 지금은 "곧 열림" 표시 |

- **포지션군 태그**(`pos`: 공용/공격/미드/수비)는 종류와 따로 붙는다. 수비 플레이 카드는 `type: 'play'` + `pos: 'def'`다.
- **희귀도 4단계**: 일반(회색), 희귀(라임), 에픽(보라), 전설(금색). 발광, 금박, 광택은 쓰지 않는다(기존 규칙).

### 덱과 패 (카드 화면에 숫자로 나오는 규칙)
- 덱은 **8장으로 시작**하고, 위상 티어가 오르면 **최대 14장**까지 늘어난다. 보상 면담의 "덱 슬롯 +1"은 이번 시즌에만 적용되고 14장을 넘지 않는다. 기존 화면의 "기본 12"는 예시 값이므로 그대로 둬도 된다.
- 같은 카드는 2장까지, 세트피스는 덱에 3장까지.
- 경기 시작 때 패 4장, 15분마다 1장 드로우, 장면에 성공하면 보너스 1장(경기당 최대 3장). 패는 최대 6장이고 한 턴에 1장만 쓴다.
- 한 행동에 붙는 카드 확률 보너스는 합계 **최대 +15%p**다. 카드는 능력치를 올리지 않는다.
- **숙련도**: 같은 카드를 쓸수록 효과가 조금 오른다. 5회 +2%p, 15회 +4%p, 30회 +6%p(최대). 확률 카드에만 해당한다. 카드 `level` 표시에 쓴다(Lv1~4 = 0/5/15/30회).
- **고위험 고보상**: 화려한 플레이 카드는 성공하면 평점이 크게 오르고 실패하면 내려간다. 카드 상세에 성공/실패를 같이 보여 준다.

### 획득 경로 (획득 연출, "새 카드" 배지용)
- 일반: 시작 덱 8장, 레벨업 5레벨마다 3장 중 1장 고르기
- 희귀·에픽: 시즌 종료 보상(3장 중 1장), 업적, (5단계) 시즌 목표 보상과 카드 상점
- 전설: 레전드 배지, 큰 업적(발롱도르, 월드컵 우승)
- 시그니처: **그 역할로 10경기 출전하면 해금**("해금까지 7/10경기" 같은 진행 표시가 필요)

## 2. 그림 방향

- 스타일: 기존 기본 그림(조명 아래 골문, 수비벽, 공 궤적)과 같은 계열의 **평평한 2D 일러스트**. 그라데이션 장식, 발광, 망점은 쓰지 않는다. **공의 궤적이나 움직임 선은 희귀도 색**으로 그린다(기존 규칙).
- 한 장면 = 한 동작. 선수는 얼굴 없이 실루엣이나 단순한 형태로 그린다(내 선수의 생김새가 플레이마다 다르므로). 유니폼은 중립색으로 하고, 특정 실존 팀이나 선수를 떠올리게 하지 않는다.
- **같은 계열 카드는 구도를 맞춘다.** 슛 계열은 골문 정면, 패스 계열은 위에서 내려다본 피치와 화살표, 수비 계열은 낮은 각도의 몸싸움, 세트피스는 수비벽이나 페널티 지점, 관리 계열은 상징 아이콘형(손바닥, 숨, 카드 뒤집기)으로 한다.
- 그림 영역은 full 카드(280×392)의 사선 위쪽이다. 원본은 2배 해상도로 만들고, mini·hand 크기로 줄여도 동작이 읽혀야 한다(가운데에 주 동작 하나).
- 에셋 이름: `card-<id>.png`(id는 아래 표의 영문 id). 에셋 그룹 `CardArt`에 둔다.

## 3. 카드 목록

표기:
- **조건**은 화면 문구 형식("조건 · …")으로 바로 쓸 수 있게 적었다. 능력치 숫자는 그 능력치의 최소값이다.
- **효과**는 `{상황}에서 {행동}하면 {무엇}이 **{수치}** …해요` 형식이다. 굵은 글씨가 `hi`(희귀도 색 강조) 칸이다.
- ★ = 시작 덱 카드(조건이 모두 60 이하로 낮아진 값).

1. **카드 그림 76장**(지시 3장 포함, 전설 후보 3장은 선택). 같은 계열은 구도를 맞춘다. 먼저 **시작 덱 18종**(공격·미드·수비 덱의 서로 다른 카드)과 **에픽·전설 4장**(파넨카, 라보나 크로스, 엘라스티코, 바이시클 킥)부터 한다.
2. **카드 갤러리 화면 1장**: 76장을 deck 크기로 종류별·희귀도별로 늘어놓은 시트. 효과 문장과 조건이 카드 칸에 넘치지 않는지 확인하는 용도다(가장 긴 문장 기준: 라움도이터, 침투형 스트라이커, 컴플리트 윙백).
3. **획득 연출 2장**: ① 3장 중 1장 고르기(레벨업·시즌 종료 보상), ② 시그니처 해금("역할 포처로 10경기 출전, 원터치 마무리 해금").
4. **시그니처 해금 진행 표시**: 덱 편집 카드 풀에서 잠긴 시그니처 카드의 `locked` 상태(예: "7/10경기").
5. **숙련도 표시**: 카드 상세의 Lv1~4와 다음 단계까지 남은 사용 횟수(예: "Lv2 · 다음 단계까지 9회").

## 6. 하지 않는 것
- 카드 상점과 카드팩 화면(5단계, 19.6)은 이번 범위가 아니다.
- 숫자를 그림 안에 넣지 않는다(수치가 바뀔 수 있다).
- 실존 선수, 실존 팀 엠블럼, 실존 유니폼을 떠올리게 하는 그림은 쓰지 않는다.
