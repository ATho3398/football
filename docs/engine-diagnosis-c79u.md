## 3. 행 레버인가 상호작용 레버인가 (엔진관리자14 c78z §3 분해로)
- 점유 가치는 **행 레버**다 — "그 성향이 모두에게 조금 강해진다"(중간 ⅓ 상실 −6%, 상대 전환 기회 −7~27%). 성향별 값이 다르므로(티키 0.018 ~ 직선·블록 0) 행 이전이 생기고, 합이 0 이라 받지 못한 직선·블록·버스 행이 내려간다. 1·3·4차 세 행 9/9 음수, 합 −0.11 로 일정 — 이것이 "행 레버로 상호작용 칸을 건드린다" 는 엔진관리자14 진단과 **같은 구조**(C.78w 2단 체력, C.78y H1 과 같은 종류).
- 거기에 **상호작용 한 쌍이 있을 수 있다**(1.5σ, 미확정): 직선 대 (역습·균형) — 직선의 보통 수비가 중간 ⅓ 점유를 블록의 깊은 밀집보다 더 많이 실점으로 바꾸는 쪽. 있다면 점유 가치의 "거리·자리·성향" 식 어디에도 없는 **직선 수비의 성질**이라 점유 가치 상수로는 안 움직인다. 확정 여부와 무관하게 1~4차 조정이 옮겨 다닌 것은 행 잡음이다.
- 4차 fit 의 "역습 +0.07 · 직선 −0.07" 은 (행 이전 −0.04/+0.03) + 잡음(±0.033, 같은 엔진 두 시드에서도 역습 +0.04 가 나왔다) 으로 충분히 설명된다. **행 ±0.05 를 480 한 벌로 판정하는 한 어떤 조정도 안정적으로 못 넘는다.** 판정은 ① 비점유 3행 합(이전 크기, SE ±0.03) ② 960 두 시드 평균 행 ③ 칸·순환은 기록만(SE 2배 넘게 움직인 것만 적는다).
