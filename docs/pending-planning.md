# 기획서 반영 대기 (코드 세션 실행 중에 확정한 결정)

코드 세션(E3.5 2차 → E3.6 → E3.7)이 돌고 있어 `game-design.md`를 고치지 않고 여기에 모은다. 코드 세션이 쉬면 본문에 합치고 이 파일을 지운다.

## 확정 (2026-10-15, 사용자: 추천대로)
1. **E5-lite를 앞당긴다.** 순서: E3.5 2차 → E3.6 → **E5-lite** → 사람 확인 → E3.7 → E4 → E5(완성).
   - E5-lite = 현재 UI 스타일로 엔진 위치 프레임(E.13)을 재생하는 피치 화면. 22명 마커와 공, 배속(1×/2×/4×), 일시정지, 건너뛰기, 이벤트 피드. 결정 순간 정지와 선택 패널은 없다(E4). 렌더러는 E5 완성 때 그대로 확장할 수 있게 24.4 `MarkerRenderer` 구조로 만든다.
   - 이유: 역할 31개(E3.7)를 넣기 전에 기본 엔진이 축구처럼 보이는지 사람이 눈으로 확인한다.
   - 반영할 곳: 17번 로드맵, 17.1, E.17, H.1, 상단 필독 가이드(E5-lite: 24, E.13, E.14).
2. **면담 보상(18.3) 개정**(디자인 제안 채택): 보상 면담(신뢰도 80 이상) 선택지 3개 = 주전 보장 / 선호 슬롯 보장(다음 5경기) / 덱 슬롯 +1(이번 시즌 한정, 최대 14장을 넘지 않음). "휴식 1주"는 넣지 않는다.
3. **디자인 결과물 보관(완료)**: 수정본(규칙 불일치 13곳 수정, 예전 경합패널 삭제, 화면 47장)을 `docs/design/player-one-design/`에 넣었다. 디자인 적용(U단계)은 이 폴더의 `HANDOFF.md`부터 읽는다. 남은 사소한 샘플 값 2곳(홈 주전 경쟁의 경쟁자 폼 +2.5는 범위 ±1.5 밖, 전술 화면 CDM 슬롯의 역할 "박스투박스"는 CM 역할)은 U단계 때 실제 데이터로 바뀌므로 무시한다. 본문에 합칠 때 21번·부록 I·H.5에 이 폴더를 디자인 기준으로 적는다.
4. **메모(U단계 전 기획)**: 복잡도 관리(단계적 공개: 처음엔 전술 성향·포메이션만, 역할·세부 전술·커스텀은 나중에 또는 "고급" 토글)와 첫 플레이 안내(첫 결정 순간, 첫 덱 편집, 첫 훈련 계획). 마일스톤마다 사람 확인 체크리스트는 각 확인 직전에 기획 세션이 만든다.

## 추가 확정 (2026-10-15, E3.5 2차 진행 중 막힘에 대한 결정, 사용자: 전달)
코드 세션이 E3.5 2차 5번(보정)에서 막혔다: 실제 선수 시즌에서 강팀 압도(토트넘 시즌 136~159골, 케인 90골+), 시즌 XP 비 1.17~1.26 고정, ST 득점 94~98%, 스탯 반응 ST 슈팅 +10 → 득점 +45%(기준 +12%의 4배, 슈팅 수 +20%가 주원인: 동료가 좋은 마무리 선수에게 몰아줌).
5. **E.15에 상한과 실제 시즌 목표를 추가한다.**
   - 스탯 반응 상한: 각 항목의 크기는 표 기준값의 2.5배 이하(예: ST 슈팅 +10 → 득점 +12~30%). 하한(방향 확실 + 기준의 70%)은 그대로.
   - 실제 선수 시즌 목표(실제 선수 모드, 3시즌 평균): 최다 득점 팀 85~105골, 최다 실점 팀 60~85골, 득점왕 22~38골, 우승팀 승점 85~100.
6. **E5-lite를 E3.5 2차 완료보다 먼저 한다.** 지금까지 작업은 작업 브랜치에 커밋 → 위 5번 목표를 측정에 추가(맞추지 못해도 됨) → 경량 가드를 임시로 넓혀(XP 비 0.85~1.3, 그 밖에 현재 실패 항목은 기록) `main`에 배포 → E5-lite → 배포하고 멈춤. 사람이 경기를 보고 진단한 뒤 E3.5 2차 보정을 이어 간다. E3.6(전술 화면)은 그다음.
   - 임시 가드는 부록 C에 "엔진 보정 중 임시 범위"로 기록하고, E3.5 2차가 끝나면 원래 범위로 되돌린다.

## 추가 확정 2 (2026-10-15, 한 선수 시즌 100골·ST 득점 94~98% 해결, 사용자: 추천대로, "ST 비중부터")
E.20에 구조 변경 7~11번으로 넣는다(합칠 때). 우선순위는 ST 쏠림을 먼저 푸는 ①②.
7. **① 슈팅 결과 = 기회의 질 × 마무리 배수.** 골 확률 = 그 슈팅의 xG(위치, 각도, 압박, 슈팅 종류, 상대 GK 능력·위치) × 마무리 배수. 마무리 배수 = clamp(1 + 0.012 × (마무리 능력치 − 70), 0.8, 1.25), 마무리 능력치 = 슈팅·결정력·침착성 가중(중거리는 중거리 슛). 결정력 계열이 유효 슈팅·슈팅 속도·코너 정확도·선방에 따로따로 곱해지던 것을 이 한 곳으로 모은다. 검증: 선수별 득점/xG 0.8~1.25, ST 슈팅 +10 → 득점 +12~30%.
8. **② 수비 주의 집중.** 상대 공격수 중 위협도(마무리 능력치 × 골까지 가까움)가 가장 높은 1명은 마크 거리 × 0.6, 박스 안이면 가까운 수비 2명이 붙을 수 있다. 그 선수에게 가는 패스의 수신 압박이 자연스럽게 커지고, 빈 동료의 기회가 늘어난다(할당 금지, E.15.1). 검증: 최고 ST 경기당 슈팅 3~5개, 팀 슈팅 중 ST 비중 35~45%, ST 득점 비중 38~48%.
9. **③ 약팀의 상대별 대응(AI 감독).** 경기 전 상대가 레이팅 5 이상 강하면 AI 팀은 라인·압박을 한 단계 내리고, 성향을 수비 블록/역습으로 바꿀 확률 50%. 내 팀(사용자 전술)에는 적용하지 않는다.
10. **④ 경기 상황 효과.** 2골 이상 앞선 팀은 위험한 선택(침투 패스, 드리블 돌파, 먼 슛) 효용 가중 × 0.85와 템포 감소, 3골 이상이면 × 0.75. 지고 있는 팀은 70분 이후 기존 규칙대로 라인·압박을 올린다. 모든 팀에 같은 규칙.
11. **⑤ 모든 능력치에 같은 S자 체감 곡선**(한 곳에서 적용). 70→80 효과 100%, 80→90 약 70%, 90→99 약 40%. 슈팅 계열은 7번 마무리 배수가 상한을 잡으므로 따로 더 꺾지 않는다.
- 진행: 코드 세션 중단 → 커밋 → ①② → 측정 → ③④⑤ → 측정(E.15 + 실제 시즌 목표 + 스탯 반응 상한) → 임시 가드로 main 배포 → E5-lite → 배포하고 멈춤.
