# 5단계 착수 전 보강 초안 (기획 세션 작업 중)

코드 세션이 돌고 있는 동안 여기에 모으고, 쉬면 18~22번과 부록에 합친다.

## ③-1 감독 신뢰도와 선발 (확정 2026-10-15, 18.1~18.3 개정)
1. **선발 = 내가 고른 슬롯에서 실제 경쟁자와 선발 점수 비교.**
   - 선발 점수 = 슬롯 포지션 OVR + (신뢰도 − 50) × 0.06 + 폼 보정(−1.5~+1.5, D.1 폼 5단계) − 피로 보정(피로 70 이상 −2)
   - 경쟁자 = 그 슬롯에 들어갈 수 있는 팀 동료 중 선발 점수 최고(NPC 신뢰도 60 고정, 폼은 시드)
   - 선발 확률 = clamp(L((내 점수 − 경쟁자 점수)/1.5), 0.15, 0.97). 0.15는 로테이션 몫이다.
   - 벤치면 지금처럼 `subChance` 0.5로 15~30분 교체 투입.
   - 기존 식(`0.8 + (OVR − 팀 레이팅) × 0.04`)을 대체한다. 빠른 경기 경로도 같은 식을 쓴다.
   - **조건: `npm run balance` 회귀 가드를 통과하도록 계수(0.06, 1.5, 0.15)를 맞춘다.** 출전 시간이 성장 밸런스를 바꾸기 때문이다.
2. **홈 "주전 경쟁" 카드**:
   - 신뢰도 게이지
   - 나와 경쟁자 2~3명의 선발 점수 막대(항목별 분해: 슬롯 OVR / 신뢰도 / 폼 / 피로)
   - 최근 신뢰도 변화 이유 5개
   - 다음 면담 조건
3. **신뢰도 변화 추가**:
   - 경고 −1, 퇴장 −5
   - 교체 출전 경기의 평점 보정(±2)은 절반(±1)
   - 부상 결장 중에는 변화 없음
   - 기존: 평점 7.0 이상 +2 / 6.0 미만 −2, 골·도움 각 +1, 승 +1 / 패 −1, 독단 카드 실패 −5
4. **"포지션 제안" 면담 추가**: 내가 고른 슬롯 OVR이 내 최고 포지션 OVR보다 5 이상 낮은 상태로 3경기 이상 뛰면 열린다. 감독이 최고 포지션을 제안하고, 따르면 신뢰도 +3, 거절하면 변화 없음. 강제하지 않는다.
5. **18.1 문장 수정(합칠 때)**: "역할/성향은 경기 장면 선택지의 기본 순서와 확률 보정에만 쓰인다" → "역할/성향은 움직임과 판단 선호(층 3, 4)만 바꾸고 성공 확률은 바꾸지 않는다(`docs/roles-draft.md` 층 구조)". 역할 적합도의 평점·XP 보너스는 유지한다.

## ③-2 이벤트 데이터 구조 (확정 2026-10-15, 20번 보강)
1. **조건·효과는 데이터 형식**:
   - 조건 예: `{ all: [ {var: "trust", op: "<", value: 30}, {var: "date", op: ">=", value: "D+60"} ] }`, all / any / not 조합.
   - 변수 목록은 고정한다: 위상, 신뢰도, 피로, 폼, 돈, 시즌 기록, 팀 순위, 라이벌 지표, 플래그, 날짜·시즌 단계, 직전 경기 결과·하이라이트.
   - 효과 상한(이벤트 1개당): 위상 ±5, 신뢰도 ±10, 돈은 주급 4주분 이내.
   - 테스트로 모든 이벤트가 존재하는 변수·플래그만 참조하는지, 상한을 넘지 않는지 검사한다.
2. **한국어 템플릿**:
   - 템플릿마다 변형 문장 3개 이상
   - 조사 자동 처리(`{name}{은/는}`, `{이/가}`, `{을/를}`, `{과/와}`, `{으로/로}`, 받침 판별)
   - 톤(칭찬/중립/비판)은 위상 티어와 직전 결과로 고른다.
3. **초기 이벤트 약 60개**: 선택형 25, 정보형 30, 연쇄형 5. 경기 하이라이트 연동 이벤트를 포함한다(결승골 → 인터뷰, 퇴장 → 비판 기사 등).

## 전 경기 엔진과 캘린더 (확정 2026-10-15)
4. **다른 팀 경기도 전부 22명 엔진으로 계산**한다(사용자: "자동 돌리면 엔진 다 돌아가도 됨. 시즌당 수 분도 괜찮음. FM처럼 최대 속도로. 대신 중단 가능하게").
   - 내 경기가 아닌 경기는 위치 프레임 기록 없이 결과와 선수 기록만 계산한다.
   - Web Worker 여러 개로 병렬 처리한다(`navigator.hardwareConcurrency`).
   - 내 경기도 자동이면 화면 재생 없이 최대 속도로 계산한다.
   - 선수 개인 기록(골, 도움, 평점 등)이 모든 선수에게 생기고, 라이벌·득점 순위·이적 평가에 쓴다.
   - 빠른 경기(`simulateMatch`)는 남긴다: 커리어 밸런스 시뮬(`npm run balance`)용, 그리고 설정의 "빠른 진행" 옵션용(느린 기기). 기본값은 전체 엔진이다. 엔진과 빠른 경기의 팀 결과 분포가 비슷한지 점검을 유지한다.
5. **하루 단위 진행(FM식)** — 2번(시간 진행)을 개정한다.
   - 게임 시간은 하루 단위다. **[계속]** 버튼은 다음 일정(경기, 이벤트, 응답이 필요한 일)까지 자동으로 넘기고, **[하루 진행]** 버튼도 둔다.
   - 날을 넘길 때 그날 열리는 다른 경기를 엔진으로 계산해 결과를 낸 뒤 다음 날로 간다.
   - 진행 중 **[중단]**을 누르면 그날 경기까지만 끝내고 멈춘다. 하루 단위로 저장해 이어서 진행할 수 있다.
6. **일정은 2018-19 프리미어리그 패턴으로 생성**한다(시드로 대진).
   - 8월 둘째 주 개막, 5월 중순 종료
   - 주말 중심, 주중 라운드 4~5회, 박싱데이 연전
   - 컵(5-6)은 비는 주중에 끼워 넣는다.
7. **주 단위 시스템을 날짜 단위로 환산**하고, 주간 합계는 지금과 같게 유지한다.
   - 피로: 하루 회복량 = 주간 회복량 ÷ 7
   - 부상 기간: 일 단위
   - 주급: 매주 월요일
   - 이벤트: 주차 슬롯 → 날짜
   - 세이브: 날짜 저장, 기존 세이브 변환
   - 커리어 밸런스 점검 통과가 조건이다.
8. **시점**: 5단계 맨 앞에 **"5-0 캘린더"** 덩어리를 둔다(하루 단위 진행, 전 경기 엔진 병렬 계산, 중단·재개, 훈련). 순서: E4 → E5 → 3단계 카드 → 4단계 잔여 → 5-0 → 5-2 …
