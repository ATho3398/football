# 설계 메모

## 게임 컨셉
- 선수 한 명을 정해서 키우는 싱글 플레이 커리어 모드 (FC 시리즈 커리어, 감독이 아닌 선수 시점)
- 직접 축구 플레이는 하지 않음. 경기는 시뮬레이션이고, 11 vs 11 장면은 2D 피치에서 연출형으로 보여줌
- 배포/수익 없음, 개인용. 실제 선수 데이터 사용(라이선스 무관)
- 플랫폼: 웹(TypeScript) 우선, 필요하면 Tauri(PC)/Capacitor(모바일)로 포장

## 데이터 방침
- 실제 유명 선수는 제 기억 기반으로 능력치 작성, 나머지는 절차적 생성(가상 선수)
- 기준 시점: **2018년 여름** (2018-19 시즌 시작)
- 대상 리그: 5대리그, K리그, 잉글랜드 챔피언십, 독일 2부, 에레디비지
- 5대리그는 인지도 Top 3팀(EPL은 Top 6)의 주요 선수 전원 + 리그 내 인기도 Top 30
- 영어 이름으로 데이터 작성, 한글 이름은 `nameKo`로 따로 관리

## 세 가지 축
| 축 | 질문 | 변화 | 보임 |
|---|---|---|---|
| 실력 | 지금 얼마나 잘하나 | 나이, 훈련, 폼 | 보임 (능력치에서 자동 계산되는 티어) |
| 위상 | 얼마나 대단한 선수로 여겨지나 | 업적 쌓이면 상승, 하락은 매우 느림 | 보임 (이적, 연봉, 스폰서, 기사) |
| 잠재력 | 얼마까지 클 수 있나 | 성장하며 서서히 확정 | 숨김 |

- 티어 5단계: 레전더리 > 월드클래스 > 탑클래스 > 스페셜(임시 이름) > 일반
- 실력 티어는 능력치(OVR)에서 자동 계산. 위상(명성 점수 + 레전드 배지)과 잠재력 티어는 데이터에 직접 기록
- 잠재력은 현재 실력과 독립 (현재 일반, 잠재 레전더리 가능)
- 레전드 배지: 업적(발롱도르, 월드컵 우승, 챔스 우승 N회 등) 달성 시 영구 부여. 내 선수도 획득 가능
- 예: 메시(2018) 실력 월드클래스+, 위상 레전더리 / 현재 일반이지만 잠재력 레전더리인 유망주도 가능

## 능력치 (필드 플레이어 25개, 0~100) — 묶음 7개
- 볼 다루기(2): 드리블, 볼 컨트롤
- 마무리(4): 슈팅, 중거리 슛, 헤더, 공격 위치선정
- 패스·시야(5): 숏패스, 롱패스, 크로스, 프리킥, 시야
- 수비(4): 태클, 인터셉트, 마킹, 수비 포지셔닝
- 스피드·민첩(3): 속도, 가속, 민첩성
- 피지컬(3): 체력, 근력, 점프
- 멘탈(4): 침착성, 결정력(큰 경기 집중력), 리더십, 노력
- 제거한 항목: 퍼스트터치(볼 컨트롤에 통합), 페널티킥(슈팅+침착성으로 계산), 밸런스(민첩성에 통합), 판단력(시야에 통합)

### 골키퍼 (플레이 불가, NPC 전용, 25개와 별개)
- 유형 2개: 스위퍼 키퍼 / 클래식 키퍼
- 능력치 4개: 선방(반사신경·다이빙), 핸들링, 출전 범위(공중볼 포함), 킥(배급)
- 유형에 따라 출전 범위·킥 가중치가 달라짐

## 능력치 랜덤 생성 (새 게임 시작 시)
- 데이터에는 능력치를 확정하지 않고 **중심값**만 기록 (선수당 25개, 실제 선수는 기억 기반)
- 새 게임마다 시드로 중심값 주변에서 랜덤 결정. 시드를 저장해 같은 세이브는 항상 같은 결과
- 변동은 3단계로 합산:
  1. 선수 전체 운(1개): 모든 능력치에 공통 적용. 회차마다 선수 수준이 눈에 띄게 달라지게 함
  2. 묶음별 운(7개 묶음): 같은 묶음 능력치가 함께 움직여 어색한 조합(볼 컨트롤 높은데 드리블 낮음 등)을 방지
  3. 개별 흔들림: 능력치마다 작게
- 일부 능력치는 두 묶음에 약하게 걸침 (헤더: 마무리+피지컬, 결정력: 멘탈+마무리 등). 근력↑이면 민첩성 약간↓ 같은 반대 방향 연동도 가능
- 변동 폭은 규칙으로 지정: 기본 ±5, 스타는 좁게(±3), 무명·유망주는 넓게(±8). 특정 선수/능력치만 예외로 범위를 직접 지정 가능
- 위상(reputation)과 레전드 배지는 사실 기반이라 고정. 잠재력은 범위에서 랜덤 가능
- 실력 티어는 랜덤 결과 능력치에서 자동 계산되므로 회차에 따라 달라질 수 있음 (허용)

## 선수 데이터 필드 (1단계)
id, name, nameKo, birthYear, nationality, height, weight, foot, club, league, shirtNumber, position, subPositions, attributes(중심값), variance(선택, 변동 폭 예외), traits(플레이스타일/특수능력 태그), potentialTier, reputation, legendBadge, gkType(골키퍼만)

## 구현 단계
1. 선수 스키마 + 주요 선수 JSON 작성 (티어 높은 선수부터)
2. 성장/노화/폼/부상 시스템, 내 선수 생성
3. 경기 시뮬레이션 (이벤트 기반 확률 엔진), 텍스트 중계
4. 계약/이적 시장, 명성, 스토리 텍스트
5. 2D 피치 연출, 가상 리그 확장, 런처 포장
