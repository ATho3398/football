# 설계 메모

## 게임 컨셉
- 선수 한 명을 정해서 키우는 싱글 플레이 커리어 모드 (FC 시리즈 커리어, 감독이 아닌 선수 시점)
- 직접 축구 플레이는 하지 않음. 경기는 시뮬레이션이고, 11 vs 11 장면은 2D 피치에서 연출형으로 보여줌
- 배포/수익 없음, 개인용. 실제 선수 데이터 사용(라이선스 무관)
- 플랫폼: 웹(TypeScript) 우선, 필요하면 Tauri(PC)/Capacitor(모바일)로 포장

## 데이터 방침
- 실제 유명 선수는 제 기억 기반으로 능력치 작성, 나머지는 절차적 생성(가상 선수)
- 기준 시점: **2018년 여름** (2018-19 시즌 시작)
- 대상 리그: 5대리그, K리그, 잉글랜드 챔피언십, 독일 2부, 에레디비지
- 5대리그는 인지도 Top 3팀(EPL은 Top 6)의 주요 선수 전원 + 리그 내 인기도 Top 30
- 영어 이름으로 데이터 작성, 한글 이름은 `nameKo`로 따로 관리

## 세 가지 축
| 축 | 질문 | 변화 | 보임 |
|---|---|---|---|
| 실력 | 지금 얼마나 잘하나 | 나이, 훈련, 폼 | 보임 (능력치에서 자동 계산되는 티어) |
| 위상 | 얼마나 대단한 선수로 여겨지나 | 업적 쌓이면 상승, 하락은 매우 느림 | 보임 (이적, 연봉, 스폰서, 기사) |
| 잠재력 | 얼마까지 클 수 있나 | 성장하며 서서히 확정 | 숨김 |

- 티어 5단계: 레전더리 > 월드클래스 > 탑클래스 > 스페셜(임시 이름) > 일반
- 실력 티어는 능력치(OVR)에서 자동 계산. 위상(명성 점수 + 레전드 배지)과 잠재력 티어는 데이터에 직접 기록
- 잠재력은 현재 실력과 독립 (현재 일반, 잠재 레전더리 가능)
- 레전드 배지: 업적(발롱도르, 월드컵 우승, 챔스 우승 N회 등) 달성 시 영구 부여. 내 선수도 획득 가능
- 예: 메시(2018) 실력 월드클래스+, 위상 레전더리 / 현재 일반이지만 잠재력 레전더리인 유망주도 가능

## 능력치 (약 25개, 0~100)
- 기술: 슈팅(마무리), 중거리 슛, 헤더, 롱패스, 숏패스, 크로스, 드리블, 퍼스트터치, 볼 컨트롤, 프리킥, 페널티킥
- 수비: 태클, 인터셉트, 마킹, 수비 포지셔닝
- 신체: 속도, 가속, 체력, 근력, 점프, 민첩성, 밸런스
- 멘탈: 시야, 침착성, 결정력(큰 경기 집중력), 판단력, 리더십, 노력, 공격 위치선정
- 골키퍼: 반사신경, 다이빙, 핸들링, 킥, 출전 범위, 1대1

## 선수 데이터 필드 (1단계)
id, name, nameKo, birthYear, nationality, height, weight, foot, club, league, shirtNumber, position, subPositions, attributes, traits(플레이스타일/특수능력 태그), potentialTier, reputation, legendBadge

## 구현 단계
1. 선수 스키마 + 주요 선수 JSON 작성 (티어 높은 선수부터)
2. 성장/노화/폼/부상 시스템, 내 선수 생성
3. 경기 시뮬레이션 (이벤트 기반 확률 엔진), 텍스트 중계
4. 계약/이적 시장, 명성, 스토리 텍스트
5. 2D 피치 연출, 가상 리그 확장, 런처 포장
