# UI 디테일 결정 초안 (기획 세션 작업 중)

코드 세션이 돌고 있는 동안 여기에 모으고, 쉬면 16번, 부록 E.11, F.5, F.6, 부록 I(I.4, I.5)와 `docs/ui-spec-for-design.md`에 합친다.

## 확정 (2026-10-15)
1. **결정 순간 구조 = C(혼합)**: 직접 모드에서는 결정 순간마다 멈추고, 선택지 3개(안전/균형/도박) 중 하나를 고르고 카드를 0~1장 쓴다. 귀찮으면 **"맡기기" 한 번 탭**으로 그 순간을 엔진에 넘긴다.
   - 맡긴 순간은 엔진 판단(E.7)으로 처리하고, **카드는 쓰지 않는다**(패에 남는다). 카드를 아꼈다가 중요한 순간에 쓰는 판단이 직접 플레이의 가치가 된다.
2. **경기 중 언제든 직접 ↔ 자동 전환**: 경기 화면 상단 속도 컨트롤 옆에 토글을 둔다.
   - 자동으로 바꾸면 다음 결정 순간부터 엔진이 처리한다. 카드는 F.5 자동 규칙(조건 맞는 첫 카드 사용)을 따른다.
   - 직접으로 바꾸면 다음 결정 순간부터 멈춘다.
   - 전환에 벌점은 없다. 평점과 XP는 실제로 일어난 플레이로만 계산한다.
