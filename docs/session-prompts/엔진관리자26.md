## 할 일
- 1번: 크로스 순간 박스 안 공격 인원을 막는 단계를 연결 고리로 쪼개 잰다(침투 판단 발동 빈도 → 침투 경로가 오프사이드 라인·수비 줄에 막히는지 → 도착 시간이 크로스보다 늦는지 → 다른 판단(지원·각도)에 밀리는지). 어느 고리가 병목인지 수치로.
- 2번: 슛 뒤 흐름(막힌 슛·GK 쳐냄·골대) → 루즈볼 첫 접촉 팀·거리 → 재슈팅까지 시간·확률. 실축 기준(쳐낸 공의 몇 %가 공격 팀에 가는지 등)과 비교해 병목 찾기.
- 각 병목에 **처방(상수 이름·방향·크기, 수치 레버 우선; 구조 변경이 꼭 필요하면 최소 범위)** + 예상 영향(득점·상성·이동 거리). 실험 스위치로 처방 1~2개를 짧게(300경기) 확인까지.
