## 할 일
1. **일반 구조 `ENGINE.decide.bias`(새 블록)**: 행동 종류별(shoot·pass·through·dribble·cross·clear·hold 등) 판단 효용 보너스 = 기본값 × 상황 함수. **판단(choose) 효용에만 들어가고 실행 확률·결과에는 절대 안 들어간다**(결과 할당 아님). 기본 전부 0 — 이번엔 shoot만 쓴다. 상황 함수는 판단에 보이는 특징만 쓴다(슛 레인 열림·거리·각도·압박·GK 자리 등), 결과·점수·시간 맞추기 금지.
