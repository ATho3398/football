## 할 일
1. **결정 순간 숫자 통일**(실제 게임 기준): 선택지마다 보이는 성공 확률·위험 등급·기대 평점(·엔진 선택 표시)이 같은 계산에서 나오게. 규칙: 위험 등급 = 실패 시 평점 손실 기준 ≤0.02 낮음 / 0.03~0.05 보통 / >0.05 높음, 기대 평점 = p×이득 − (1−p)×손실, 4번째 선택지(카드 선택지)는 카드를 고른 뒤에만 보임. 지금 코드에서 각 숫자의 출처를 표로 남기고 어긋나는 곳만 고친다. 결정 결과 판정 확률 자체는 바꾸지 않는다(표시만).
2. **내 선수 잠재력 범위 표시(B6 결정)**: 선수 화면·홈 선수 카드에 "잠재력 78~84"처럼 범위로. 범위 폭은 나이가 들수록 좁아짐(예 17세 ±6 → 27세 이후 ±1, 실제 잠재력이 범위 안에 있게, 시드 고정이라 새로고침해도 같은 값). 정확한 하나의 값은 보이지 않는다. NPC 표시 방식과 어긋나지 않게.
