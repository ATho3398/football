## 할 일 (AD 결정: FM식 기본값)
1. 다른 경기 계산 설정을 3단계로: **[내 리그만 엔진(기본)] · [전부 엔진] · [전부 빠른 진행]**. 내 리그(내 팀이 속한 리그)·내 팀이 나가는 컵의 같은 라운드 경기는 엔진, 다른 리그·내 팀 없는 컵 경기는 빠른 진행(점수 확률 + 득점자 추첨/기록 추정 — 기존 빠른 진행 경로 재사용).
2. 내 리그 득점왕·도움 경쟁·시상 후보·순위 목표는 엔진 기록 그대로, 다른 리그 시상·발롱도르 후보는 기존 추정 경로가 자연스럽게 섞이는지 확인(내 리그 엔진 기록 + 다른 리그 추정 기록 비교 가능한 척도인지 — 발롱도르 후보 분포가 한 리그로 쏠리지 않게, 필요하면 추정 쪽 보정 수치).
3. 기존 세이브: 설정 값이 세이브에 있으면 **세이브 이전 단계**로 옛 '전부 엔진' 사용자는 그대로 두고, 기본값을 쓰던 사용자만 새 기본값으로(판단해서 기록). SAVE_FORMAT 올리면 이전 단계 + fixture 테스트.
4. 설정 화면 설명 한 줄씩: 각 단계가 무엇을 바꾸는지(속도·다른 리그 기록 정밀도).
